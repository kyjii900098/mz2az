**3) 높아지는 수요에 반하는 정보 탐색·이동 설계의 번거로움**
- 콘텐츠 **촬영지 정보**는 블로그, 유튜브, SNS, 팬 커뮤니티 등에 파편화되어 존재하며, 사용자는 원하는 촬영지를 찾기 위해 **다수의 검색 과정을 반복**해야 함
- 또한 촬영지를 찾더라도 **실제 방문 가능한 위치인지 확인하기 어렵고**, 여러 장소를 연결한 여행 **일정 설계 역시 직접 수행**해야 하는 **불편함이 존재**함
- DUCPIC, K-Spotter, K-Spot Tour, Seichi 와 같은 **유사 서비스가 존재**하나, 일부는 **아이돌 방문지 중심이거나 작품 수와 데이터가 부족**함
- 외국인 관광객의 20.2%는 한국 여행 준비 시 부족했던 정보로 **'교통 정보'**를 꼽았으며, 이는 콘텐츠 기반 방문 수요가 실제 여행 동선 설계 단계에서 불편으로 이어질 수 있음을 보여줌[3]

> [!note] 막대그래프: "K-콘텐츠가 방한 수요를 만들지만, 이동·교통 정보는 여전히 불편 요소"
> - 한류 콘텐츠를 접하고서 방한 여행 관심: 31.9%
> - 한국 전통문화를 접하고서 방한 여행 관심: 28.7%
> - 과거 방문 경험이 좋아서 방한 여행 관심: 26.7%
> - 여행 준비 시 부족했던 정보: 교통 정보: 20.2%
>
> 추가 근거: K팝 한류스타 공연장 및 드라마·영화 활영지 방문 13.8%(2019 Q4) → 14.8%(2023 Q4) / 쇼핑 활동 66.2%(2019 Q4) → 59.5%(2023 Q4) → 콘텐츠 기반 방문 수요는 늘고, 단순 쇼핑 중심 관광은 약화되는 흐름
>
> 출처: 동아일보, "외국인 관광객 3명중 1명 '한류 콘텐츠 접하고 여행 관심", 2024.03.12

**기획의도**
- K-콘텐츠의 인기로 드라마, 영화, 예능, K-POP속 실제 장소를 방문하려는 '성지순례' 수요가 증가
- 하지만 촬영지 정보는 블로그, 유튜브, SNS, 팬 커뮤니티 등에 흩어져있어 사용자가 원하는 장소를 찾기 위해 여러번 검색해야 함
- 장소를 찾은 뒤에도 실제 위치, 이동 방법, 주변 관광지, 방문 후기 등을 다시 확인해야 하는 번거로움이 존재
- SceneTrip은 이런 불편을 줄이기 위해 K-콘텐츠 촬영지 정보를 한곳에 모으고, AI를 통해 검색부터 일정 추천 및 생성까지 연결하는 것을 목표로 함

## p5

#### 프로젝트 개요

**프로젝트 소개**
- SceneTrip은 K-드라마, 영화, 예능, 뮤직비디오 등에 등장한 실제 촬영지 정보를 통합해 외국인 관광객에게 제공하는 K-콘텐츠
- 사용자는 콘텐츠별 촬영지를 지도에서 확인하고, 위치·방문정보·교통정보를 함께 파악가능
- 여행중에는 현재 위치와 시간을 기준으로 다음 방문할 장소를 추천하며, 사용자는 방문 루트를 공유하고 커뮤니티에서 다른 팬들과 정보를 나눌수 있음

**주요 기능**

| 구분 | 내용 |
|---|---|
| 주요 기능1 | 콘텐츠별 성지 정보 제공<br>- 콘텐츠 별 성지 데이터 구축 및 지도 기반 위치 시각화<br>- 배우명, 작품명을 통한 통합 검색 기능<br>- 실시간 개방 여부, 운영시간 조회 |
| 주요 기능2 | AI기반 여행 일정 추천<br>- 여행지에서 현재위치를 기준으로 다음에 방문할 장소를 추천<br>- 사용자의 현재 위치를 실시간으로 인식, 이동 효율을 극대화한 최적의 동선 설계<br>- 여행 이전, 사용자의 선호에 따른 AI기반 여행 계획 수립 |
| 주요 기능3 | 루트공유 및 커뮤니티 기능<br>- 자신만의 성지순례 루트와 방문 인증 기록을 블로그 형식으로 공유<br>- 팬덤간의 상호작용을 통해 실시간 여행 팁과 촬영지 최신 상태 공유<br>- 사용자가 직접 정보를 검증하고 축적하는 참여형 커뮤니티 운영을 통한 고품질 데이터의 선순환 구조 확립 |

> [!note] 이미지: '성지순례' 앱 UI 스크린샷 3장 — ① 작품명 검색/필터(전체·드라마·영화·예능·넷플릭스), 콘텐츠별 성지 목록과 평점 카드 ② 실시간 위치 반영 화면 — 지도에 성지 핀 표시, "OO맹공 청담 ── 앤딩씬 찍힘을 만나는 브이로그 투어" 카드, 방문 진행률(1/4 완료), 다음 추천 성지 리스트 ③ 커뮤니티 지도 공유 화면 — 팬들의 루트 공유 게시물 리스트(발하늘별, 드라마여행, 케탄텐클럽, 서울탐험가 등 닉네임과 코스명)

**시스템 구성도**

> [!note] 시스템 아키텍처 다이어그램. 주요 구성 요소:
> - **Public Entry**: Route 53 DNS → CloudFront + WAF + ACM + TLS + Cache + 기본보호 → Application Load Balancer / EKS Ingress (HTTPS)
> - **클라이언트**: Flutter 모바일 앱(iOS/Android, 외국인 중심 K콘텐츠 매핑), 관리자 Web(장소 후보 승인/수정, 제보·사진·레뷰 검수)
> - **CI/CD**: Amazon ECR Container Images, Github Actions
> - **AWS VPC / Multi-AZ — Private subnet: Amazon EKS Cluster**
>   - K8S Ingress: AWS Load Balancer Controller
>   - Domain Service: User/Content/장소, Route/Nearby, UGC/Review, Admin/Moderation
>   - Data Automation Workers: Crawler CronJob, ETL/normalize, LLM Extraction, LLM Verification, RAG Indexer
>   - API Gateway
>   - AI & Search Service: Chatbot(Personalized), Recommendation, Search/RAG
> - **Managed Service / Data Layer**: RDS PostgreSQL + PostGIS(사용자·관리자·장소·리뷰·루트·UGC), OpenSearch Service(키워드/벡터 검색, RAG 인덱스), Amazon S3(사진/영상/공식 원본/정형/정제 데이터), ElastiCache Redis(세션/인증정보 캐시, 지도/AI 재세션), EventBridge + SQS(스케쥴 작업 큐)
>   - Amazon Bedrock(LLM 생성/추천·추출 Agent), CloudWatch/Prometheus/Sentry(로그 매트릭·알림), Secrets Manager + KMS(API Key/DB Secret)
> - **External APIs / Sources**: Youtube, 공식자료 블로그/커뮤니티(K-콘텐츠 접속 실린 데이터), Google/Kakao/OSM/Foursquare(지오코딩, POI, 길찾기)

**AI 활용 전략**

> [!note] 플로우차트 1 — "성지 데이터 자동 구축 파이프라인"
> 데이터 수집(대상 URL 스캔·HTML→본문 추출·게시일/출처 메타 수집) → LLM 정제(장소명 추출·작품명/에피소드 매핑) → 검증 Agent(지도API 좌표 실존 확인·중복 병합/병합·신뢰도 점수 산출) → 성지 DB(장소·작품·좌표 저장·신뢰도·갱신일 관리·벡터 임베딩 인덱싱)
> [검증 Agent 루프] 신뢰도 점수 미달 → 수집대상 확장 → LLM 재정제 → 재검증 반복 3회 실패 시 관리자 검수 큐로 플래그
> ▶ 기대효과: 수작업 DB 구축 대비 90% 이상 공수 절감. 검증 루프로 좌표 오류·허위 성지 유입 사전차단

> [!note] 플로우차트 2 — "여행 일정 자동 생성 (여행 前)"
> 사용자 입력(관심 콘텐츠 선택·여행 기간·인원) → 선호도 분석(장르·팬 성향 프로파일링·과거 방문 이력 반영) → 후보 필터링(성지 DB 검색·이동 시간·거리 필터·운영시간·계절) → LLM 플래너(시간순 동선 최적화·식사·이동 구간 삽입) → 맞춤 일정(지도 핀·순서 표시·시간표·교통편 안내)
> ▶ 기대효과: 동일 드라마 팬도 기간·이동수단·인원에 따라 개인화 일정 자동 생성. 사전 조사 시간 대폭 단축

> [!note] 플로우차트 3 — "위치 기반 실시간 성지 추천 (여행 中)"
> GPS 위치(실시간 좌표 수신) → 위치 분석(반경 내 성지 DB 조회·도보·대중교통 거리 계산) → 추천 엔진(방문 이력 제외 처리·취향 가중치 적용·동일 작품 연계 우선 추천) → 장소 추천(지도 마커·장면 이미지·방문 인증 기능 연동·커뮤니티 후기 노출)
> ▶ 기대효과: 사전 계획 없이도 현장 즉각 탐방 가능, 방문 패턴 기반 연계 추천으로 체류 시간 및 방문 장소 수 증가
