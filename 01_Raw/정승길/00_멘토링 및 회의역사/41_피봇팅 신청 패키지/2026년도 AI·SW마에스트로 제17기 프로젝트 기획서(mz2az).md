**3) 높아지는 수요에 반하는 정보 탐색·이동 설계의 번거로움**

- 콘텐츠 **촬영지 정보**는 블로그, 유튜브, SNS, 팬 커뮤니티 등에 **파편화되어 존재**하며, 사용자는 원하는 촬영지를 찾기 위해 **다수의 검색 과정을 반복**해야 함
- 또한 촬영지를 찾더라도 **실제 방문 가능한 위치인지 확인하기 어렵고**, 여러 장소를 연결한 여행 **일정 설계** 역시 **직접 수행**해야 하는 **불편함**이 존재함
- DUCPIC, K-Spotter, K-Spot Tour, Seichi 와 같은 유사 서비스가 존재하나, 일부는 아이돌 방문지 중심이거나 **작품 수와 데이터가 부족**함
- 외국인 관광객의 20.2%는 한국 여행 준비 시 부족했던 정보로 '**교통 정보'**를 꼽았으며, 이는 콘텐츠 기반 방문 수요가 실제 여행 동선 설계 단계에서 불편으로 이어질 수 있음을 보여줌³

### ○ 기획의도

- K-콘텐츠의 인기로 드라마, 영화, 예능, K-POP속 실제 장소를 방문하려는 '성지순례' 수요가 증가
- 하지만 촬영지 정보는 블로그, 유튜브, SNS, 팬 커뮤니티 등에 흩어져있어 사용자가 원하는 장소를 찾기 위해 여러번 검색해야 함
- 장소를 찾은 뒤에도 실제 위치, 이동 방법, 주변 관광지, 방문 후기 등을 다시 확인해야 하는 번거로움이 존재
- SceneTrip은 이런 불편을 줄이기 위해 K-콘텐츠 **촬영지 정보를 한곳**에 모으고, AI를 통해 **검색부터 일정 추천 및 생성까지 연결**하는 것을 목표로 함

## □ 프로젝트 개요

### ○ 프로젝트 소개

- SceneTrip은 K-드라마, 영화, 예능, 뮤직비디오 등에 등장한 실제 촬영지 정보를 통합해 외국인 관광객에게 제공하는 장면기반 성지순례 지도 서비스
- 모든 촬영지는 출처·신뢰도·검수 상태를 함께 관리하며, 사용자는 콘텐츠별 촬영지를 지도에서 확인하고, 위치·방문정보·교통정보를 함께 파악가능
- 사용자는 촬영지를 엮어 자신만의 루트를 만들고, 루트 마켓에서 다른 팬이 만든 루트를 구매하거나 자신의 루트를 판매할수 있음
- 여행중에는 현재 위치와 시간을 기준으로 다음 방문할 장소를 추천하며, 사용자는 방문 루트를 공유하고 커뮤니티에서 다른 팬들과 정보를 나눌수 있음

**3) K-콘텐츠 테마 코스 큐레이션 제공**

- 지자체, 관광공사, 여행사, 로컬 투어 업체를 대상으로 K-콘텐츠 촬영지 기반 테마 코스를 **큐레이션**하여 제공
- 향후 **축적된 DB**와 사용자 방문·저장·검색 데이터를 기반으로 지역별 인기 콘텐츠, 방문 수요, 추천 루트 데이터 분석해 리포트 또는 API 형태로 확장

### ○ 기대효과

| 구분 | 내용 |
| --- | --- |
| 사용자 측면 | 영상 속 장소 탐색 시간을 줄이고 **콘텐츠 감상을 여행 계획으로 전환**. 외국인이 한국어 정보·지도·교통·주변을 **따로 찾는 부담을 낮추고, 방문 기록·공유**로 여행 경험을 팬덤 콘텐츠로 재생 |
| 비즈니스 측면 | K-콘텐츠 관심을 **지역 관광 소비로 연결**하고, 지자체·여행사·로컬 상권에 새 홍보 채널을 제공. 사용자 검색 검색·저장·방문 데이터를 기반으로 인기 콘텐츠, 지역별 방문 수요, 선호 루트 분석이 가능해 **향후 관광 데이터 비즈니스**로 확장 |
| 기타 | 외국인 관광객의 언어 장벽, 교통 정보 부족, 지역 정보 접근성 문제를 완화하여 **한국 여행 편의성 높임.** 사용자 제보와 검수 기반으로 지역 촬영지·로컬 관광 정보를 지속적으로 축적하여 **공공 관광 데이터 보완에 기여** |
