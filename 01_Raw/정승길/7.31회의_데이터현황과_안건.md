## 3. 결정 안건

1. **구글 place_id + 장소 사진 병행** — 네이버·카카오 URL은 확보 중. 구글은 API 키(결제 카드) 필요. 외국인 타겟이면 구글맵이 최종형일 가능성 — 팀 계정으로 발급할지, 개인 키로 먼저 갈지.
2. **네이버 검색형(가짜) URL 잔여 처리** — kdramamap이 준 검색형 링크 중 TOP120 외 일반 작품 행 ~1.4만은 아직 보존 중. 전부 삭제할지, 진짜 링크 배치를 전수로 확장할지.
3. **해외 로케이션 포함 기준** — 수집 조마다 판단이 갈렸음(눈물의여왕 독일 포함 vs 사랑의불시착 스위스 제외). 국내 여행 앱이므로 제외가 기본이되, 작품 정보 차원 보존 여부 결정 필요.
4. **"성지 0" 작품 처리** — 내일·고요의바다·더에이트쇼(전면 세트물)는 TOP100인데 방문 가능 촬영지가 없음 → 앱에서 "작품 정보만 노출" 처리 확정할지.
5. **장면설명 잔여** — TOP120 빈칸 3,182행은 온라인에 장면 서술 자체가 없는 케이스가 실체(4개 조 전수 시도 결과 수확률 11%). 여기서 종료하고 앱은 "장소 설명 없음" 허용할지, 상위 유명작만 사람 검수로 정밀 보강할지.
