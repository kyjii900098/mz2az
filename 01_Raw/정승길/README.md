# 정승길 작업 폴더 — 무엇을 어디에 두는가

공용 규칙(두 갈래 · 이름 규칙 · 로그 골격 · 정정 방법 · 글쓰기)은 [[01_Raw/README]] 에
있다. 이 문서에는 **내 폴더에만 해당하는 것** 을 적는다.

담당은 프론트엔드다 — iOS(Swift) · Android(Kotlin) 네이티브 앱.

## 폴더

```
01_Raw/정승길/
├── README.md              ← 이 파일
├── logs/                  ← 날마다 쌓는 작업 로그 (2주차부터)
├── 1주차_data/            ← 스프린트 산출물 (주차별)
├── 2주차_검색탭개발/
├── 3주차_.../             ← 새 주가 시작되면 만든다
├── history/               ← 프로젝트 착수 이전 기록. 아카이브, 새로 쓰지 않는다
├── 전사/                  ← 원본 문서의 무손실 전사본
└── 이미지/
```

`history/` 는 6월 아이디어 단계부터 8/3 스프린트까지의 55개 폴더다. 지난 결정의 경위를
찾을 때만 읽고 **새로 쓰지 않는다.** 지금 진행 중인 것은 전부 `logs/` 와 주차 폴더에
들어간다.

`전사/` 는 다른 사람 문서와 내 산출물의 전사본을 담는다. 프런트매터의 `source_path:` 가
원본 위치를 가리키므로, **원본을 옮기면 이 연결이 끊긴다.**

## 예외

### 1주차 로그는 `1주차_data/logs/` 에 있다

공용 규칙은 로그를 `logs/` 하나에 모으라고 하는데, 1주차 로그 4개만 주차 폴더 안에
있고 이름 규칙도 다르다(`2026-07-30-1600-codex-촬영지리서치-위임.md` 처럼 날짜가 앞).

**옮기지 않는다.** `전사/정승길/1주차_data/logs/` 에 그 4개의 전사 미러가 있고
프런트매터에 `source_path: 01_Raw/정승길/1주차_data/logs/…` 로 경로가 박혀 있어서,
옮기면 그 연결이 끊긴다. 얻는 것(폴더 하나로 모임)보다 잃는 것(전사 연결)이 크다.

**2주차부터가 공용 규칙이고, 1주차는 그 자리에 그대로 둔다.**

### 1주차 작업 폴더 일부는 git 에 올라가지 않는다

볼트 `.gitignore` 에 이렇게 걸려 있다.

```
01_Raw/정승길/1주차_data/logs/
01_Raw/정승길/1주차_data/RESEARCH/
01_Raw/정승길/1주차_data/조합작업/
01_Raw/정승길/1주차_data/codex/
```

데이터 수집 과정의 중간 산출물이라 공유할 필요가 없다고 판단해 제외했다. **Dropbox
동기화로는 넘어가지만 git 이력에는 없다.** 다른 기기에서 `git clone` 만 하면 이
폴더들이 비어 있다.

## 관련 저장소

코드는 볼트가 아니라 다른 곳에 있다. 로그에서 참조할 때 경로를 헷갈리지 않도록 적어 둔다.

| 무엇 | 어디 |
| --- | --- |
| 팀 모노레포 | `~/workspace/SceneTrip` (github.com/mz2az/SceneTrip) |
| Flutter 프로토타입 | `~/workspace/mobile` — 모노레포에 넣지 않는다. 화면·검색 규칙의 참고본 |

프로토타입을 모노레포에 넣지 않는 이유는 ADR 0002 가 크로스 플랫폼 프레임워크를
쓰지 않기로 확정했기 때문이다. 경위는 [[02_2026-08-05_검색탭 개발]] §10 에 있다.
