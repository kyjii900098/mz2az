# 영화 장면정보 분석 — Codex 전용

작성 기준: 2026-07-30  
분석 대상: `촬영지_마스터_codex.csv`

## 작업 경계

- Claude 작업 원본인 `data/` 직속 파일과 `data/조합작업/`은 읽기만 한다.
- Codex의 모든 신규·수정 산출물은 `data/codex/` 안에 저장한다.
- 마스터 수정은 `촬영지_마스터_codex.csv`에만 한다.
- 조사 중간 결과도 파일명 끝에 `_codex`를 붙인다.

## Claude 작업과의 중복 여부

`result_codex.md` 기준 Claude의 현재 B-1 작업은 다음 두 드라마의 장면 설명 조사다.

- 눈물의여왕 145곳
- 내남편과결혼해줘 117곳

이후 B-2 범위도 S등급 드라마 보강, 확정 TOP100의 A·B등급 드라마, 오징어게임2 재검수, 신규 수집 드라마 209곳이다. 영화 촬영지 또는 영화 장면 설명 조사는 현재 Claude 작업 범위에 없다.

따라서 영화 장면정보 작업은 Claude 작업과 직접 겹치지 않는다.

## 영화 데이터 현황

- 영화 행: 789행
- 고유 영화 제목: 524편
- 촬영지가 있는 영화: 47편, 308행
- 장면 설명이 있는 영화: 41편, 246행
- 촬영지는 있지만 장면 설명이 없는 영화: 6편, 62행
- 촬영지 자체가 전혀 없는 영화: 477편

`result_codex.md`의 “영화 727편 채택”은 실제로는 727개 `mv_` 행이다. 이 행들은 촬영지별로 한 영화가 여러 행을 가질 수 있으므로 작품 수와 같지 않다. `mv_` 행의 고유 제목은 521편이며, kdramamap에서 들어온 `st_` 영화 6편 중 중복을 반영한 마스터 전체 고유 영화 수는 524편이다.

| 영화 | 설명이 빈 촬영지 |
| --- | ---: |
| 길복순 | 16곳 |
| 청년경찰 | 12곳 |
| 유열의음악앨범 | 11곳 |

| 뷰티인사이드(영화) | 8곳 |

이 62행은 장소명·주소가 이미 있으므로, 각 장소가 영화의 어떤 장면에 등장했는지 검증해 `scene_description`만 채우면 된다.

## 촬영지부터 새로 수집해야 하는 2차 대상

촬영지 자체가 없는 영화는 477편이다. 이 작품들은 장면 설명만 채울 수 없고 다음 순서가 필요하다.

1. 방문 가능한 실제 촬영지 확인
2. 장소명·주소·좌표·근거 URL 수집
3. 해당 장소의 영화 속 장면 확인
4. Codex 전용 신규 행 파일로 저장
5. 검수 후 `촬영지_마스터_codex.csv`에 병합

우선순위는 관객수와 수상 내역을 함께 사용하는 것이 적절하다. 관객수 상위 미수집 작품에는 `신과함께-죄와 벌`, `국제시장`, `서울의 봄`, `도둑들`, `7번방의 선물`, `범죄도시2`, `광해, 왕이 된 남자`, `파묘`, `부산행` 등이 있다.

## 권장 Codex 작업 순서

1. 기존 촬영지 62곳의 장면 설명 조사
2. 6편 단위 검수와 출처 확인
3. 관객수·수상 기준으로 촬영지 없는 영화의 우선순위 목록 생성
4. 우선순위 영화별 신규 촬영지 수집
