# (07.06) 멘토방향 정리

<callout icon="🧭" color="blue_bg">
	기획안 제출 → **평가의견(피벗 권고)** 수령 → 정문창·김상규·방한민 멘토님과 상의(07.04~07.05)한 내용을 하나로 정리한 문서. 결론은 **"주제는 유지하되(소프트 피벗), 종합 여행앱처럼 보이는 부분을 걷어내고 K-컨텐츠를 메인으로 뾰족하게"**.
</callout>
# 1. 왜 피벗 얘기가 나왔나 (평가의견 요지)
심사위원 4개 항목의 공통된 지적:
- **차별화 부족** — 일반 여행 서비스와 기능적 차이를 발견하기 어렵다. Visit Seoul 한류관광 대신 *우리를 써야 할 결정적 이유*를 한마디로 정의해야.
- **핵심 고객 미정의** — 누가, 왜 쓰는지가 모호.
- **수요 검증 미완** — 외국인 Pain Point가 아직 데이터로 입증 안 됨. (권고: Reddit r/kdrama·r/kpop, MyDramaList에서 **8월까지 N≥100 설문**, 방문 의향·정보탐색 불편도·지불 의향 측정)
- **BM 취약** — 구독의 핵심은 반복 결제인데 본 서비스는 **일회성 결제 위주 → 구독 성립 어려움**. 수익모델 다양화 필요, 사업화 가능성 물음표.
- **데이터·저작권** — 크롤링 이미지의 저작권 이슈, 자동 매칭의 난이도·최신성 유지 문제.
- **긍정 요소** — 크라우드소싱 커뮤니티, 지방 분산 **B2G(지자체 연계)**, 데이터 라이선싱 확장 잠재력은 인정.

# 2. 세 멘토 공통 진단 (수렴점)
<callout icon="✅" color="green_bg">
	세 분 모두 방향은 조금씩 달라도 아래 4가지에는 사실상 동의.
</callout>
1. **"종합 여행앱" 프레임을 벗어나라.** 지금 기획서를 읽으면 트리플·비짓코리아 같은 일반 여행앱으로 보인다 → 컨텐츠(작품·연예인)를 **전면에** 내세워야 차별화가 생긴다.
2. **뾰족하게 / 범위 축소.** 이것저것 다 하려 해서 뭉뚱그려져 있다. 킬러 피쳐 3~4개로 MVP를 좁혀라.
3. **구독이 아니다.** 반복 결제가 안 생기는 구조 → **패스(원타임)·건당 구매·플랫폼 수익분배** 쪽으로 BM을 다시 짜라.
4. **검증부터.** 목업과 사용자 인터뷰/설문으로 먼저 확인하고 살을 붙여라.

# 3. 멘토별 핵심
## 🔴 정문창 멘토님 (07.04) — 투자자 관점, 가장 냉정
- **"돈을 어떻게 벌 건데?"** 투자자는 몇 년 뒤 10배·100배를 본다. 광고 모델 = *사실상 돈 벌 수단이 없다는 말*. 타겟(외국인 10~30대)은 광고 단가가 낮다.
- **여행앱이면 못 이긴다.** 부킹닷컴·야놀자·여기어때·트리플… 여행상품 구조상 플랫폼이 수수료를 다 나눠먹는다. 레드오션.
- **그래서 직접 고부가가치를 팔아라.** K-컨텐츠 기반 **여행 코스/투어 상품**을, 사람 가이드 대신 **앱이 인솔·설명·루트 제공**하는 형태로. (하루짜리 ≈ 5만원 수준)
- **규모 냉정하게.** 3억 벌려면 3만원짜리를 1만 건(10만 유입×10% 전환) → J커브 근거를 그림으로 제시.
- **성지화도 우리가 만든다.** 대만 센과치히로 사례처럼, 성지 아닌 곳도 컨텐츠 발굴로 부가가치화. 별그대·케데헌 같은 킬러 컨텐츠 하나로 루트 여러 개.
- **당장 할 것:** 동백꽃 필 무렵(부산 배경) 같은 걸로 **각자 루트 1개씩 직접 짜보기**. 발로 뛴 루트·사진·버스 번호 디테일 = 킬러 피쳐. 포토스팟(구도까지)·여행 후 스토리북/카드뉴스도 아이디어.
- 지자체(기장군·칠곡군 등) 관광 지원과와 공공 목적 연계도 가능. VisitKorea 이기는 건 쉽다.
- **마감:** 킬링 피쳐 3~4개 + 돈 되는 논리를 다듬어 **~7/14 서류 재제출**.
## 🟢 방한민 멘토님 (07.05) — 소프트 피벗, 가장 낙관적 · 실행 구체적
- **"주제는 좋다. 나쁘다고 한 적 없다." 소프트 피벗이면 충분.** 주제·타겟은 유지하되 종합여행앱처럼 보이는 요소를 걷어내라.
- **핵심은 메인뷰.** 컨텐츠가 화면을 차지해야 한다. (예: BTS 마커 → 누르면 그 씬 → 연동된 포인트 → 아티스트가 한 얘기·공유 사진) 기존 여행앱은 날씨·장소정보가 메인 → **우리는 컨텐츠가 메인 = 차별화**. "우리가 보여줄 메인뷰가 뭔지"를 아직 디파인 안 한 게 문제.
- **카니발라이제이션 경고.** 우리 피쳐가 좋으면 대기업이 3~6개월이면 따라한다. 트래픽 없는 우리가 진다 → 쉽게 못 따라할 것(컨텐츠·루트 **검증을 AI로 어떻게 퀄리티 있게**)에 집중.
- **AI는 추천이 아니라 검증/검수에.** 주변 밥집 추천은 대기업이 더 잘함(메인 X). 컨텐츠-장소 매핑 정확도, 유저 컨텐츠 검수에 AI를 써라.
- **BM = 패스 + 플랫폼.** 구독 아닌 **패스(원타임, 에버랜드 자유이용권처럼 여러 종류)**. 마일스톤: ①패스로 단기 트래픽 확보 → ②데이터 축적 후 **B2B는 다음 페이즈**. 나아가 **유저가 루트를 만들고 수익 분배 → 플랫폼화**(초기 시드 컨텐츠는 우리가 제작, 툴 제공).
- **3명 합의:** 유저 컨텐츠 업로드 O · 우리 포맷 제작 툴 제공 O · 유저 보상 O.
- **당장 할 것:** **목업 먼저(50~60 페이지).** 유튜브 임베딩 + 위치 json + 지도로 돌아가는 목업을 빨리 → Claude 디자인으로 이터레이션. 도메인 사고 **이름도 K-컨텐츠 쪽으로** 변경.
- 인프라: 인스턴스 1~2개(xlarge)면 충분, LB 없이, 깃헙 액션 스케줄로 야간 자동 다운. 경로: 정류소 위치는 공공데이터에 다 있음, **버스 이동 path 데이터는 찾아봐야**(카카오부터).
## 🟡 김상규 멘토님 (07.04) — 실무·제약 점검
- **⚠️ 소마 기간에는 실제 수익 창출 금지.** BM은 "구매 의사가 있느냐"를 검증하는 수준으로(구독 결제라도 받아만 놓기).
- **데이터는 공공·오픈으로.** 저작권 이슈가 덜하다. PoC는 수작업이라도 OK.
- **수요 검증이 결정적.** 다음 한 주에 **최소 5명이라도 외국인 인터뷰**. 서면역·부산역·김해공항에서 팜플렛/QR로 바로 다운로드 유도. 설문 2종(한국에 관심 갖고 온 사람 / 아닌 사람)으로 분기.
- **저작권 회피 아이디어:** 사진 여러 장을 받아 AI로 합성·생성(광안대교 등)해 저작권 회피.
- **강점 보강 필요** — 크라우드소싱만으로 되겠나? AI 활용 포인트(사진 구도 등)를 더 명확히.
- 월요일 A3 칠판에 그려가며 정리(2시~).
