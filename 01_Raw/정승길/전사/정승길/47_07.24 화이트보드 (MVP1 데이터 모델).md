## 001 — 초기 상태

제목은 화이트보드 상단 가운데에 **`MVP1`** 이라고 쓰여 있다. 그 아래 5개 컬럼이 나란히 놓이고, 컬럼 사이는 짧은 가로선(`—`)으로 이어져 있다.

| 컬럼 | 색 | 내용 |
| --- | --- | --- |
| **장면** | 검정 | 아래 참조 |
| **장소** | 검정 + 빨강 | 아래 참조 |
| **코스** | 검정 | 아래 참조 |
| **커뮤니티** | 검정 | `[게시판]` 박스 하나뿐 |
| **유저** | 파랑 | 빈 박스만 그려져 있고 내용 없음 |

### 장면

```
[ 영상 이미지 ]        ← 박스
        |
   ( 메타 정보 )
        |
   장면 설명            ← 빨강
                 ) 1 : N
                 ( 장소 : 장면 )
```

`1:N (장소:장면)` 은 **장소 하나에 장면이 여럿 붙는다** 는 관계 표기다. 중괄호 `)` 로 「메타 정보 ~ 장면 설명」 묶음을 감싸 그 관계를 가리키고 있다.

### 장소

```
[ 실제 장소 이미지 ]    ← 박스
  ( 구글 API 이미지 - 대표 )   ← 박스 바로 아래 작은 글씨
        |
   ( 메타 정보 )
        |
   리뷰 ( 이미지, )
        user            ← "이미지," 아래에 작게

   POI 정보             ← 빨강
```

장소의 대표 이미지는 **구글 API에서 가져온다** 는 것, 리뷰는 **이미지와 유저(작성자)** 를 함께 갖는다는 것이 핵심이다.

### 코스

```
[ 당긴 정보 ]           ← 박스. 판독 불확실 (아래 참조)
        |
   ① 순번
   ② 설명 ( 여행계획 )
```

> [!question] 판독 불확실 — 코스 박스 안의 낱말
> 7배 확대·대비 보정으로도 확정하지 못했다. 글자 모양은 「**당긴 정보**」에 가깝게 보이나 뜻이 통하지 않는다. 획으로 보아 후보는 `당긴 정보` / `당건 정보` / `단건 정보` / `일반 정보` 정도다.
> 다른 컬럼의 박스가 전부 **그 엔티티의 대표 콘텐츠**(영상 이미지 · 실제 장소 이미지 · 게시판)를 담고 있으므로, 코스의 대표 정보를 가리키는 말일 가능성이 높다. 원본 작성자에게 확인이 필요하다.

### 커뮤니티 / 유저

- **커뮤니티** — `[게시판]` 박스 하나. 하위 항목 없음
- **유저** — 파란 펜으로 컬럼 제목과 빈 박스만 그려져 있다. 이 시점엔 내용을 안 채웠다

## 002 — 논의가 더해진 나중 상태

001의 내용이 그대로 남아 있고, 그 위에 **빨강·파랑 주석** 이 얹혀 있다. 아래는 **추가된 부분만** 적는다.

### 장면 컬럼에 추가

- **포스터 API** — 빨강, 밑줄. 「장면 설명」 아래에 적혀 있다. 작품 포스터를 API로 가져온다는 뜻으로 보인다

### 코스 컬럼에 추가 (빨강)

```
② 설명 ( 여행계획 )
   ↳ 작품과 관련된 설명
     ( 같은 장소라도 어느 장면 보고 온 건지 )
```

**같은 장소여도 어느 작품·장면을 보고 왔느냐에 따라 코스 설명이 달라져야 한다** 는 것. 장소가 아니라 **장면** 이 코스의 단위라는 이 회의의 핵심 결론에 해당한다.

### 장면 → 코스를 잇는 파란 곡선 화살표

「장면 설명」 근처에서 출발해 「② 설명(여행계획)」의 `↳` 로 들어가는 큰 곡선 화살표가 있고, 곡선 아래에 라벨이 붙어 있다.

- **축약 : LLM**

즉 **장면 설명을 LLM으로 축약해 코스 설명으로 만든다** 는 흐름이다.

### 좌하단 파란 메모

- **MVP1 범위** — 밑줄. 아래 메모들이 MVP1 범위 논의라는 표시
- **팝업** — 원으로 감싸져 있다. `현지 활성화` 에서 화살표가 이 원으로 들어간다
- **현지 활성화 —→** (팝업)
- **코스만 늘리면**
- **동적 / 정적** — 밑줄

> [!question] 판독 불확실 — 좌하단 메모의 맥락
> 낱말 자체는 읽히지만 서로 어떤 논리로 이어지는지는 화이트보드만으로 알 수 없다. 「코스만 늘리면」 뒤에 이어질 말이 없고, 「동적/정적」이 무엇의 구분인지도 적혀 있지 않다.
> 같은 날짜 노트 `46_2026-07-24 로드맵.md` 와 대조해 맥락을 채워야 한다.

### 우측 빨강 다이어그램 (판독 어려움)

유저 컬럼 오른쪽 여백에 빨간 펜으로 원 3~4개를 화살표로 이은 그림이 있다. 이미지 저장 방식을 논의한 흔적으로 보인다.

- 왼쪽: 큰 원 안에 작은 사각형 (라벨 판독 불가)
- 가운데: 원 두 개가 겹쳐 있고 안에 **`파일`** / **`이름`** 으로 읽히는 글자. 아래에 밑줄 두 줄
- 오른쪽: 원 안에 사각형 **`DB`** (밑줄)
- 아래쪽: 사각형 안에 `이미…` 로 읽히는 글자 (**`이미지`** 로 추정), 오른쪽 원에서 화살표가 들어온다

> [!question] 판독 불확실 — 우측 빨강 다이어그램
> 4배 확대·대비 보정으로도 글자 대부분을 확정하지 못했다. 화이트보드 오른쪽 끝이라 조명 반사가 겹쳤고 획이 흐리다.
> 배치와 `DB`·`파일`·`이름`·`이미지` 로 읽히는 조각만 보면 **이미지 원본을 DB에 넣을지 파일로 두고 이름만 DB에 넣을지** 를 저울질한 그림으로 보이나, 이는 **해석이지 판독이 아니다.** 원본 작성자 확인 필요.

### 중앙의 지워진 흔적

화이트보드 가운데 아래쪽에 크게 지운 자국이 있고 `이마 별` · `그을` · `장소별` · `낭 신간위` 처럼 부분적으로만 읽히는 글자가 남아 있다. 지워진 이전 논의라 복원 불가능하다.

## 이 화이트보드에서 확정된 것

전사본 범위에서 사실로 읽을 수 있는 것만 적는다.

1. MVP1의 엔티티는 **장면 · 장소 · 코스 · 커뮤니티 · 유저** 5개다
2. 장소와 장면은 **1:N** 관계다 (장소 하나에 장면 여럿)
3. 장소 대표 이미지는 **구글 API**, 작품 포스터는 **포스터 API** 로 가져온다
4. 리뷰는 **이미지 + 작성 유저** 를 갖는다
5. 코스 설명은 **작품과 연결된 설명** 이어야 하며, 같은 장소라도 어느 장면을 보고 왔는지에 따라 달라진다
6. 장면 설명 → 코스 설명 변환에 **LLM 축약** 을 쓴다
