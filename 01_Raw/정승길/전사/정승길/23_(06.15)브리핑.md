# (06.15)브리핑

# 1. 현재 잡은 프로젝트 주제
## 한 줄 설명
**K-콘텐츠 장면을 실제 여행 동선으로 바꿔주는 AI 비주얼 맵/루트 추천 서비스** 입니다.

## 주제 배경
처음에는 애니메이션 성지순례 정보 제공 아이디어에서 출발
다만 애니메이션 성지순례는 일본 중심으로 흐를 가능성이 커서,
한국으로 범위를 변경

현재는 **외국인 관광객 또는 K-콘텐츠 팬** 을 대상으로, 한국 드라마·영화·뮤직비디오 촬영지를 지도 위에 보여주고, 각 촬영지를 여행 코스로 연결해주는 서비스를 생각

## 사용 시나리오
1. 사용자가 좋아하는 드라마, 영화, 배우, 아이돌, 뮤직비디오, 장면을 검색합니다.
2. 서비스가 관련 촬영지를 지도 위에 노드처럼 보여줍니다.
3. 각 노드에는 작품명, 장면 설명, 장소 정보, 공식 영상/이미지 링크, 방문 팁, 주변 맛집/카페 정보가 붙습니다.
4. 사용자가 가고 싶은 노드를 선택하면 이동 시간, 동선, 주변 장소를 고려해 루트를 추천합니다.
5. 여행 후에는 찍은 사진을 바탕으로 SNS 캡션이나 블로그 후기 초안을 만들어주는 기능까지 확장할 수 있습니다.

# 2. 왜 이 주제를 선택했는가
## 문제의식
K-콘텐츠를 보고 한국에 관심을 갖는 외국인은 많지만, 실제로 특정 장면의 촬영지가 어디인지,
어떻게 갈 수 있는지, 주변에 무엇이 있는지 찾는 과정은 불편

촬영지 정보는 블로그, SNS, 팬 커뮤니티, 기사, 지도 리뷰 등에 흩어져 있고, 외국인 입장에서는 한국어 검색, 지도 서비스, 교통, 번역, 장소 검증까지 모두 부담

## 우리가 만들고 싶은 가치
단순히 "여기 촬영지입니다"라고 알려주는 지도가 아니라, **콘텐츠 소비를 실제 관광 경험으로 전환** 하는 서비스

즉 K-콘텐츠의 장면을 다음과 같이 바꾸는 것
- 장면 → 실제 장소
- 실제 장소 → 지도 노드
- 지도 노드 → 여행 루트
- 여행 루트 → 현장 경험
- 현장 경험 → SNS/후기 콘텐츠

# 3. 지금까지 받은 긍정적 피드백
## 방향 전환은 좋다
애니메이션만 보면 일본 중심이 되기 쉬운데, 한국 드라마·영화·뮤직비디오·K-pop 촬영지로 바꾸는 방향은 한국형 프로젝트로 더 자연스럽다

## 외국인 타깃은 설득력이 있다
한국인은 이미 네이버 지도, 블로그, 인스타, 유튜브를 어느 정도 활용할 수 있지만, 외국인은 한국어 정보 탐색과 지도/교통/장소 검증에서 더 큰 불편을 겪을 수 있음

따라서 외국인 관광객 또는 국내 외국인 유학생을 초기 타깃으로 잡는 방향은 설득 가능하다는 의견

## 지도와 콘텐츠를 결합하면 데모가 직관적이다
그냥 텍스트 설명보다, 지도 위에 촬영지 노드를 찍고 장면 정보와 루트를 함께 보여주면 심사위원이나 사용자에게 빠르게 이해될 수 있다는 피드백

## B2C뿐 아니라 B2B 가능성도 있다
사용자용 앱뿐 아니라, 여행사, 지자체, 관광공사, 로컬 상권과 연결될 수 있다는 의견. 예를 들어 인기 드라마나 뮤직비디오가 뜰 때 관련 장소를 빠르게 큐레이션해 여행 상품이나 지역 관광 코스로 만들 수 있음

## 포트폴리오 요소가 많다
데이터 수집, 검색, 지도, 경로 추천, RAG, 멀티모달 검색, AI Agent, 백엔드 운영툴, 모바일 UX까지 엮을 수 있어 팀원별 기술적 성과를 만들기 좋다는 피드백

# 4. 지금까지 지적받은 문제점
## 1. 저작권 리스크
가장 많이 나온 문제. 드라마, 영화, 뮤직비디오 장면을 이미지나 영상으로 직접 서비스에 올리면 저작권 문제가 발생할 가능성

따라서 공식 영상 링크, 공식 이미지, 임베드, 출처 기반 장면 설명, 사용자 직접 촬영 사진 등으로 설계해야 할 필요성 or 비기술 멘토의 피드백

## 2. 촬영지 데이터 확보 난이도
서비스의 핵심은 촬영지 데이터인데, 이 정보가 구조화되어 있지 않음.
블로그, SNS, 기사, 커뮤니티, 영상 설명, 팬덤 글 등에 흩어져 있고, 장소명/주소/위경도/작품명/장면 설명까지 연결해야 함.

## 3. 시장 크기와 사용 빈도
외국인이 K-콘텐츠 때문에 한국에 관심을 갖는 것은 맞지만, 실제로 특정 촬영지만 따라다니는 여행 수요가 충분히 큰지는 검증이 필요하다는 지적.

또한 외국인 관광객은 한 번 쓰고 이탈할 수 있어, 일반 앱처럼 높은 리텐션을 기대하기 어렵다는 피드백도 있음.

(다만 또 다른 멘토님은 이 지점이 꼭 치명적인 문제만은 아닐 수 있다고 봄. 한국 여행객이 매달 반복해서 들어오는 서비스는 아닐 수 있지만, 여행 서비스 특성상 **기존 유저의 재방문보다 매번 새로 유입되는 여행객에게 선택받는 구조** 로 볼 수 있다는 의견. 리텐션이 낮더라도 K-콘텐츠 기반 장소 DB와 코스 큐레이션 영역을 계속 넓혀가면, 한국을 방문하는 새로운 외국인 관광객에게 반복적으로 노출될 수 있음.)

추가로 걸림돌은 유저 확보 방식. 유럽/대만/동남아/미국 등 외국인이 한국 자유여행을 계획할 때 실제로 어떤 앱, 검색어, 커뮤니티, SNS를 쓰는지 알아야 하고, 우리가 그 동선 안에서 어떤 가치로 선택받을 수 있는지 검증해야 함.

또 촬영지만으로 시장을 너무 좁히면 위험하므로, K-콘텐츠 촬영지를 중심에 두되 외국인이 접하기 어려운 로컬 스팟, 맛집, 카페, 축제, 체험, 사진 명소를 함께 섞어 **한국 자유여행 큐레이션** 으로 확장할 수 있어야 한다는 보완 의견도 있었음.

## 4. AI가 억지로 보일 위험
지도에 핀을 찍고 루트를 추천하는 수준이면 AI 프로젝트로 보이지 않을 수 있습니다.

"LLM에게 여행 일정 짜줘" 수준이면 ChatGPT와 차이가 약하기 때문에, 저희만의 데이터 구조화, 멀티모달 검색, 위경도/이동시간 기반 루트 생성, RAG, Agent 평가 지표가 필요하다는 피드백을 받았습니다.

## 5. 비즈니스 모델 불명확
앱 유료화나 배너 광고만으로는 약하다는 피드백이 있었습니다. 주변 식당/카페/체험 제휴, 쿠폰, 여행사/지자체 B2B, 프리미엄 일정 생성 같은 현실적인 수익화 구조를 고민해야 합니다.

# 5. 현재 생각 중인 구현 방향
## 핵심 기능 MVP
1. **K-콘텐츠 비주얼 맵**
	- 지도 위에 촬영지 노드를 표시합니다.
	- 각 노드는 작품명, 장면 설명, 장소 정보, 공식 출처 링크, 방문 팁을 가집니다.
2. **장면/작품 기반 검색 (+배우검색)**
	- 작품명, 배우, 아이돌, 장면 설명으로 촬영지를 검색합니다.
	- 가능하면 이미지 검색 또는 멀티모달 검색 PoC를 붙입니다.
3. **루트 추천**
	- 사용자가 선택한 촬영지 노드들을 이동 시간과 위치 기반으로 묶어 반나절/하루 코스를 추천합니다.
	- 주변 맛집, 카페, 사진 스팟, 교통 정보도 함께 붙입니다.
4. **여행 후 콘텐츠 생성**
	- 방문 장소와 사용자가 찍은 사진을 기반으로 SNS 캡션, 블로그 후기 초안을 생성합니다.

## AI 활용 방향
현재 생각하는 AI 활용은 다음입니다.
- 비정형 웹/블로그/영상 설명 데이터를 촬영지 DB로 구조화
- 작품명, 장면 설명, 이미지 입력을 촬영지 후보와 연결하는 멀티모달 검색
- RAG 기반으로 촬영지 추천 근거와 출처 제공
- 위경도, 이동시간, 영업시간, 사용자 선호도를 도구로 쓰는 루트 추천 Agent
- 허위 정보, 중복 정보, 저작권 위험 정보를 검수하는 내부 운영 도구

## Agent를 나눈다면
1. **촬영지 후보 탐색 Agent**
	- 작품명/장면/이미지/자연어 입력에서 후보 장소를 찾고 출처와 신뢰도를 검증합니다.
2. **루트 설계 Agent**
	- 후보 장소의 위경도, 이동시간, 주변 정보, 사용자 선호도를 기반으로 코스를 만듭니다.
3. **콘텐츠 생성 Agent**
	- 사용자의 방문 기록과 사진을 바탕으로 SNS/블로그용 콘텐츠를 생성합니다.

# 6. 아직 결정하지 못한 부분
## MVP 범위
전국 단위로 할지, 부산 특화로 할지, 서울/부산 대표 콘텐츠 중심으로 할지 아직 고민 중.
현재는 **부산 특화 또는 서울/부산 대표 콘텐츠 5~10개 중심 MVP** 가 현실적이라고 보고 있음.

## 데이터 수집 방식
공식 관광 데이터, 블로그, 기사, 유튜브 설명, 지도 리뷰, 팬덤 자료 중 어디를 1차 소스로 삼을지...
또한 자동 수집과 수동 검수의 비율을 어떻게 가져갈지.

## 저작권 처리 방식
공식 영상 임베드, 썸네일, 장면 캡처, 사용자 업로드, 출처 링크 중 어디까지 안전한지 확인이 필요

## 실제 타깃 유저
외국인 관광객 전체로 볼지, K-drama/K-pop 팬으로 볼지, 부산 방문 외국인으로 좁힐지, 국내 외국인 유학생으로 먼저 테스트할지 정해야 함.

# 7. 오늘 여쭤보고 싶은 것
1. 이 주제가 소프트웨어 마에스트로 프로젝트로 봤을 때 충분히 설득력 있는지
2. "촬영지 지도 앱"처럼 보이지 않으려면 어떤 핵심 기능을 가장 앞에 둬야 하는지
3. 저작권 리스크를 줄이면서 이미지/영상 맥락을 보여주는 방법이 현실적으로 가능한지
4. MVP 범위를 부산 특화로 좁히는 것이 좋은지, 서울/부산 대표 콘텐츠로 가는 것이 좋은지
5. AI 요소를 어디에 가장 강하게 넣어야 억지스럽지 않고 기술적으로도 의미가 있는지
6. 데이터 수집/구조화/검수 파이프라인을 6개월 안에 어느 정도까지 잡는 것이 현실적인지
7. BM은 B2C보다 B2B/지자체/로컬 제휴 쪽으로 보는 것이 맞는지
8. 기획심의에서 가장 공격받을 포인트가 무엇일지

# 8. 지금 받고 싶은 피드백
가장 필요한 피드백은 다음 세 가지입니다.
1. **주제 자체를 계속 밀고 가도 되는지**
	- 주제가 너무 니치한지, 아니면 충분히 확장 가능한지 판단이 필요
2. **MVP를 어디까지 잘라야 하는지**
	- 6개월 안에 만들 수 있으면서도 심사위원에게 설득력 있는 범위 잡기
3. **AI/기술 포인트를 어떻게 잡아야 하는지**
	- 단순 지도/여행 추천이 아니라 AI 프로젝트로 보이려면 어떤 기술 축을 가장 강하게 잡아야 할지
