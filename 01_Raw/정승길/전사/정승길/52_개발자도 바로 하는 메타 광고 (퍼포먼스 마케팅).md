# 개발자도 바로 하는 메타 광고 (퍼포먼스 마케팅)

# 왜 메타 광고인가?
## 왜 퍼포먼스 마케팅인가?
데이터 분석 기반으로 클릭, 전환, 판매 등 측정 가능한 구체적인 성과(performance)를 목표로 하는ㄷ 디지털 마케팅 전략.

ROI를 최적화하는 데 집중

## 왜 메타?

- 타겟팅이 잘 된다.(단가가 비싸다)
- 추적 인프라의 강력함
- 압도적인 광고 지면 (instagram, facebook, thread 등)
- 실시간 제어 유연성 (소액으로도 빠른 머신러닝 학습이 가능, 실패 비용을 최소화하는 애자일 환경을 제공)

# 메타 광고 활용법
## 퍼포먼스 마케팅 사이클
1. 위닝 소재 발굴
	1. 페인포인트, 어그로끌 만한 요소
2. 실전배포
3. 데이터 분석 및 반복
	1. 데이터를 기반으로 개선 후 반복
4. 성과 기반 전략적 확장
	1. 검증된 지표(KPI) 달성 시 리스크 없이 리소스 집중 투입

# 소재 발굴
유저의 Pain Point(불편함)을 정의하고 소구점을 도출(해결 방안, 핵심 가치)

- How?
	- Canva, Miricanvas
		- 템플릿 활용(광고, 인스타용)
	- heygen
		- ugc
- 광고 소재 ideation을 위해 첨고하면 좋을 사이트
	- TikTok Top Ads
	- Facebook Ad Library
	- Google Ad Library
	- 혹은 경쟁사들의 광고
	- 유행하는 bgm
- 다다익선
	- 메타 광고는 소액으로도 빠른 검증이 가능
	- 생각 가능한 Pain Point & 소구점을 기반한 광고 소재를 모두 실험해보자(가설 검증)
- 고양이 책집사 사례
	- 책도 좋아하고 고양이도 좋아하세요? 문구
	- 내 생각엔 좀 알기 쉽게 해야 할 것 같음

# 배포
### 캠페인
비즈니스 목표 설정

- 캠페인 목표
	- 트래픽, 앱홍보 자주 쓸 것이다

### 광고 세트
타겟 정의

- 인구통계학적 필터링
- 관심사 및 행동 특성
- 광고 지면
- 타켓 고도화

### 광고

광고 만들 때 기존 게시글을 설정할 수 있음

# 데이터 분석 및 반복
- 마케팅 지표 분석
- 서비스 내 사용자 지표 분석
	- Onboarding Funnel 통과율
	- Amplitude (업계 탑)

# 성과 기반 전략적 확장
ROAS 200%
(Return On Ad Spend): 광고비 대비 매출 수익률

매출: 10000원
광고비: 5000원
구글/애플 수수료: 1500원 (3000원)
원가: x원
인건비: 0원(무보수 …)

순이익 → 3500 이하

# 메타 광고 설정 팁
1. 1 광고 세트: 1 광고
2. 메타의 알고리즘은 CTR과 CVR등 사용자 지표를 기준으로 어떤 고객들이 나의 광고에 가장 관심이 높은지를 파악한다.
	1. 타겟은 그냥 열어두는 것이 좋을 수 있다.
3. 광고 세트(소재)당 같은 예산으로 테스트
4. 광고 타깃은 최대한 넓게
5. 광고 소재의 본질을 잃지 말자

# 질문
- 어떤 기준으로 설치당 비용이 줄어드는가?
	- CPI = 총 광고 지출 비용 / 앱 설치 수 (1000회 기준)
- 우리 서비스에 적용한다면
	- 국가는 나누는게 좋고
	- 타겟층은 한국 드라마로 타겟해도 괜찮을 것 같다. 설정을 안하면 알고리즘이 동작하기 까지 시간이 좀 걸릴 것 같다.
- 광고의 사진같은거 혹시 팁이 있으신가요?
- 초반에는 앱이 없을탠데 어떻게 했는지
	- 요즘에는 실제로 만들어서 반응을 본다
	- 답은 없다
	- 작년 기수 사례는 페이크테스트(랜딩페이지)를 사용. 꽤 디테일하게 실제 결제창까지 껍데기 구현해서 결제 누르는 순간 이번 기수는 마감되었다는 메세지를 출력하고 다음 기수 알림받을 이메일 입력받로고. 그리고 그 이메일로 설문조사 발송. 만든 페이지로 메타 광고돌려봐도 괜찮을 것 같음.
