## 2. 데이터 및 데이터 컬럼

대상: 유명 드라마/OTT, K pop 관련 장소, 예능
포맷은 **CSV**, 컬럼명은 **영문으로 통일** 한다. 템플릿: `assets/촬영지_수집_템플릿.csv` (`JiraDocs/촬영지 데이터 수집용 스키마.md`, MZ2AZ-119 / MZ2AZ-120)

| 컬럼 | 한글 | 비고 |
|---|---|---|
| `title` | 작품명 | |
| `title_aliases` | 작품 별칭 | "별그대" 같은 검색용 별칭 |
| `title_category` | 작품 카테고리 | |
| `title_cast` | 관련 인물 | 배우 기준. 일단 자연어 문장으로 |
| `place_name` | 장소 이름 | 필수 |
| `place_type` | 장소 타입 | |
| `place_address` | 주소 | 좌표와 별개 저장 |
| `place_latitude` | 위도 | **소수점 5~6자리 유지** (5째 자리 ≈ 1m) |
| `place_longitude` | 경도 | 〃 |
| `place_image_url` | 사진 링크 | 필수 아님 |
| `place_naver_url` | 네이버 지도 연결 링크 | |
| `scene_description` | 작품 관련 설명 | **몇 화 몇 신** 포함 |
| `last_updated` | 마지막 업데이트 | |

- **전화번호 제외** — 외국인이 전화할 일 없음
- **영업시간 제외** — 책임져야 할 범위가 너무 넓어짐
