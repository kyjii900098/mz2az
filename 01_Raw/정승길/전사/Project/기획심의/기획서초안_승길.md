## 2. 프로젝트 기획서

### 목적 및 필요성

**문제인식**

K-Loca의 1차 사용자는 K-콘텐츠를 보고 한국 여행을 꿈꾸는 외국인 팬이다. 2024년 방한 외래관광객은 1,637만 명으로 전년 대비 48.4% 늘었고, 그중 방한 동기로 '한류 콘텐츠 접촉'을 꼽은 비율이 38.3%에 이른다. 2024 해외한류실태조사에서도 한류 경험자의 한국 방문 의향은 61.8%로 나타났다. '콘텐츠를 보다가 한국에 가고 싶어진' 외국인은 이미 거대한 수요층이며, 이들이 본 서비스의 핵심 사용자다.

그러나 이들이 '영상에서 본 그 장소'를 실제 여행으로 옮기는 과정은 번거롭다. 마음에 드는 장면을 발견해도 장소 이름을 댓글·자막·블로그·팬 커뮤니티에서 추측하고, 구글·네이버·카카오 지도에서 다시 검색하며, 영업시간·이동시간·주변 정보를 따로 확인해야 한다. 한국어와 국내 지도에 익숙하지 않은 외국인에게는 이 단계마다 진입장벽이 쌓인다.

근본 원인은 영상 속 장소가 일반 관광지 검색어와 다르게 기억된다는 데 있다. 사용자는 장소를 '작품명·아이돌·몇 분 몇 초 장면·뮤직비디오 촬영지'처럼 콘텐츠 맥락으로 기억하지만, 장소명·리뷰 중심의 일반 지도나 여행 계획 단계의 관광 포털은 '콘텐츠 장면'과 '실제 위치'를 직접 연결해주지 못한다. 그 결과 수요는 큰데도 '영상을 보는 순간'이 '여행 계획'으로 이어지지 못하고 끊긴다. 바로 이 빈 구간이 K-Loca가 푸는 문제다.

**기획의도**

K-Loca는 위 빈 구간을 메워 K-콘텐츠 감상을 한국 여행의 '발견 → 계획 → 방문 → 기록' 흐름으로 잇는 것을 목표로 한다. 저작권 리스크를 피하고 초기 데이터 부족·유입의 어려움을 극복하기 위해 다음 원칙으로 설계한다.

- 영상 시청 맥락에서 시작한다. 사용자가 공식 영상을 보는 순간 확장프로그램이 관련 장소 정보를 제공한다.
- 원본 콘텐츠를 저장하지 않는다. 영상은 공식 플랫폼에서 재생하고 서비스는 영상 ID·타임스탬프·장소명·좌표·장면 설명·공식 링크·사용자 사진·루트만 다뤄, 원본을 복제·재배포하지 않고 저작권 리스크를 최소화한다.
- 확장프로그램을 유입 채널로 쓴다. 사용자가 이미 머무는 YouTube 위에서 장소를 발견하게 하고, 상세 루트·커뮤니티·방문 인증은 웹 플랫폼으로 유도한다.
- 지도는 일반 지도가 아니라 콘텐츠 비주얼 맵이다. 핀은 작품명·영상 구간·장면 설명·방문 포인트·주변 정보를 가진 노드다.
- 데이터와 AI 파이프라인을 핵심 기술로 둔다. 차별화는 영상 속 장소를 얼마나 정확·신속하게 구조화·검증하는가에 있다.
- 6개월 MVP는 좁고 강하게 만든다. 부산·거제·서울 등 한정 지역, 대표 콘텐츠 5~10개, 영상 20~50개, 장소 노드 50~100개로 시작해 데모 완성도를 높인다.

타겟은 의도적으로 좁힌다. 1차 핵심 타겟은 방한·방한 의향 외국인 K-콘텐츠 팬과 국내 거주 외국인 유학생이며(검증 가능한 수요가 이 층에 집중), 국내 내국인 팬덤은 동일 구조로 확장할 2차 시장으로 둔다.

### 프로젝트 개요

**프로젝트 소개**

K-Loca는 K-콘텐츠 영상 속 장소를 실제 지도와 여행 동선으로 연결하는 AI 기반 브라우저 확장·웹 플랫폼이다. 사용자는 공식 영상 플랫폼에서 K-pop 브이로그·예능 클립·드라마 공식 영상·뮤직비디오·여행 콘텐츠를 시청하고, 확장프로그램은 영상의 메타데이터·자막·설명·타임라인·기존 DB·사용자 제보를 기반으로 장소 후보를 보여준다.

예를 들어 아이돌이 거제시를 방문하는 영상이라면, 해당 장면을 볼 때 오른쪽 패널에 현재 타임라인 근처 장소 후보, 지도 핀과 주소·좌표, 영상 전체 장소의 이동 순서, '이 영상 따라가기' 반나절·하루 루트, 주변 맛집·카페·포토스팟·교통, 다른 사용자의 방문 인증·제보, 웹 플랫폼 링크가 표시된다. 서비스는 확장프로그램에서 시작해 웹 플랫폼, 사용자 참여형 장소 DB, AI 루트 플래너, B2B 큐레이션으로 확장된다.

**AI 활용 전략**

AI는 단순 챗봇이 아니라 비정형 콘텐츠 정보를 장소 DB로 구조화하고, 영상 타임라인과 실제 장소를 연결하며, 맥락 기반 검색과 루트 생성을 수행하는 핵심 파이프라인이다. 또한 사용자 제보·데이터 오류를 검수하고, 개발 과정의 스펙·코드·테스트·PR 리뷰를 관리하는 데 활용한다.

**수행 방법**

최종 데모는 '사용자가 YouTube에서 K-콘텐츠 영상을 재생하면 확장프로그램이 오른쪽 패널에 영상 속 장소를 표시하고, 특정 타임스탬프 클릭 시 지도 핀·장소 카드가 열린 뒤, 이 영상 따라가기 루트와 웹 플랫폼 저장·방문 인증까지 이어지는 흐름'으로 압축한다. 초기 데이터는 대표 지역 1~2개, 콘텐츠 5~10개, 영상 20~50개, 장소 50~100개로 제한하고, AI 추출·정규화 결과는 운영자 검수를 거쳐 신뢰도를 확보한다.

사용자 확보는 국내 거주 외국인 유학생·교환학생(25.3만 명), 방한 외국인 K-콘텐츠 팬, Reddit·Discord·Instagram·TikTok 등 글로벌 팬 커뮤니티의 'this scene is here' 숏폼, 게스트하우스·국제처·관광 안내소 등 외국인 접점에서 검증한다. 개발은 스펙 기반 개발(SDD)과 AI 개발 하네스를 활용해 요구사항을 티켓으로 관리하고, 기능별 Acceptance Criteria를 작성하며, AI가 테스트·PR 리뷰 초안을 생성하고, 매주 Readiness Track으로 기획·개발·데이터·테스트·배포 상태를 점검한다.

### 결과물 및 기대효과

**결과물 형태**

- Chrome 브라우저 확장프로그램: YouTube 영상 페이지에서 동작하며 오른쪽 패널에 장소 카드·지도 핀·타임라인·루트 링크 표시
- K-Loca 웹 플랫폼·랜딩페이지: 영상별 장소 목록, 콘텐츠별 성지순례 지도, 저장 루트, 방문 인증·제보·댓글, SNS·후기 생성
- 콘텐츠-장면-장소 데이터베이스: 콘텐츠·영상·타임스탬프·장소·좌표·출처·검수 상태 저장, PostGIS 위치 검색·벡터 검색 지원
- AI 매핑·루트 추천 API: 장소 후보 추출, 검증, RAG 검색, Route Planner·UGC Moderation Agent
- 관리자 검수·운영 도구: 후보 승인·수정·보류, 제보 검수, 신뢰도 점수, 데이터 품질 지표 관리

**결과물 활용방안**

B2C 측면에서는 외국인 K-콘텐츠 팬이 영상 속 장소를 찾아 루트로 저장하고, 국내 거주 외국인 유학생·교환학생이 주변 K-콘텐츠 장소를 탐색하며, 외국인 팬덤이 방문 인증·루트를 공유한다. 여행 후 SNS 캡션·후기 생성으로 콘텐츠 확산을 유도한다. B2B·B2G 측면에서는 지자체·관광재단이 지역 테마 코스를 제작하고, 여행사가 콘텐츠 기반 투어 상품을 기획하며, 로컬 상권이 촬영지 주변 쿠폰을 노출하는 방식으로 활용한다.

| BM | 설명 | MVP 검증 방식 |
|---|---|---|
| 제휴 쿠폰·예약 수수료 | 촬영지 주변 식당·카페·체험·티켓 예약 연동 | 로컬 업체 3~5곳 인터뷰 |
| 프리미엄 루트 생성 | 팬덤·여행 스타일별 고도화 코스, PDF·공유 카드 | 무료/유료 의향 설문 |
| B2B 큐레이션 데이터 | 지자체·여행사에 콘텐츠 기반 장소·루트 데이터 제공 | 제안서·샘플 리포트 제작 |
| 광고·프로모션 | 특정 지역·행사·팝업스토어 노출 | 랜딩 트래픽 기반 테스트 |
| 팬덤 코스 제작 | 크리에이터·팬이 직접 코스 제작·공유 | UGC 코스 템플릿 검증 |

소마 과정 중에는 영리보다 사용자 검증·데이터 품질·제휴 가능성 증명에 집중하고, 과정 이후 창업·사업화 시 수익모델을 확장한다.
