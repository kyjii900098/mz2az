## 1. 작품검색 탭

> 지도 위 성지 핀 · 작품 검색 · 상세 요약 · 경로 선택

| # | UI 요소 | AI가 할 일 | 모듈 |
| --- | --- | --- | --- |
| 1 | 지도 성지 핀 + 내 위치 | **PostGIS 지리 검색** 으로 성지 좌표를 반환하고 앱이 핀을 렌더. 좌표는 M1 파이프라인이 **Geocoding** 으로 만든 데이터. 내 위치 기준 반경 검색 쿼리도 구현 | M1 수집·지오코딩 · 지리검색 |
| 2 | 검색창 | 단순 문자열이 아니라 **임베딩 기반 시맨틱 검색** — "재벌 드라마", 배우명, 오타까지 매칭. 작품·장소·배우 인덱스 구축 | M2 Vector Search |
| 3 | 인기 콘텐츠 리스트 | **인기·추천 랭킹** 생성 — 조회·검색·완주 데이터 기반 정렬. 신규 유저는 인기순 fallback | M4 추천 |
| 4 | 작품 요약 박스 | **LLM 요약** 으로 줄거리·촬영 맥락 생성 + **다국어 현지화**(외국인 타깃). RAG로 사실 근거 확보해 환각 억제 | M6 다국어 · M2 RAG |
| 5 | 성지 리스트 (씬 태그) | "어떤 장면의 촬영지인지"는 **M1 추출 파이프라인** 이 영상·글에서 뽑은 씬 정보. 항목 클릭 시 RAG로 상세 설명·팁 제공 | M1 추출 · M2 RAG |

화면 예시 문구: `작품·배우·촬영지 검색` / `눈물의 여왕 — tvN 2024 · 성지 4곳` / `줄거리 — 재벌 3세 홍해인과 백현우의 러브스토리…` / `더현대 서울 · 첫 등장 씬`

## 2. 경로여정 탭

> 경로 동선 · 경로마켓 · 여정만들기 · 실시간 AI 가이드 챗봇

| # | UI 요소 | AI가 할 일 | 모듈 |
| --- | --- | --- | --- |
| 1 | 경로 동선 · 순서 핀 | **Itinerary Planning** — 성지들을 거리·교통·영업시간 제약 하에 방문 순서 최적화(**TSP 근사**) + **Route API** 실측 동선 | M5 경로생성 |
| 2 | 경로마켓 카드 | **추천 랭킹** — 취향·평점·구매수 기반 정렬. 개인화(뚜벅이/감성/원조 등) 반영 | M4 추천 |
| 3 | 여정 만들기 (경로 빌더) | 유저가 고른 성지로 경로 생성 → **동일 검증기** 로 동선·좌표 유효성 확인 후 마켓 등록 | M5 경로검증 |
| 4 | AI 가이드 챗봇 (플로팅) | **Location-aware Agent** — 현재 위치·활성 경로를 컨텍스트로 도구 호출(`search_spots`·`get_route`·`rag_lookup`). 대화 상태 관리 | M3 Agent |
| 5 | 무료 질문 카운터 · 패스 유도 | **티어별 차등 정책** — 무료는 질문 5회 제한·요약형 답변, 패스는 무제한. 횟수는 서버에서 관리, RAG 검색범위도 권한으로 게이팅 | 권한 게이팅 · 차등 RAG |
| 6 | 근거 카드 ("검증 데이터 기반") | **RAG citation** — 답변 생성 시 검색된 출처 청크를 함께 반환해 신뢰도 표시. 환각 억제의 핵심 | M2 RAG 인용 |
| 7 | 퀵리플라이 칩 | 현재 경로·위치 맥락에 맞는 **추천 질문 동적 생성**(길안내/맛집/다음 성지). Agent가 컨텍스트로 후속 액션 제안 | M3 Agent |

화면 예시 문구: `💡 무료 AI 질문 3/5 · 무제한 →` / `＋ 내 순례 여정 만들기` / `백현우 코스 · 더현대 — by Sarah_K ⭐4.9 · $2.99` / *"첫 목적지는 **더현대 서울**, 도보 6분! 출발할까요? 🚶"* / `검증된 성지 데이터 기반` / `길 안내` `근처 맛집`

## 3. 커뮤니티 탭

> 작품별 팬포럼·동행모집 · 여행자 후기(유저 경로)

| # | UI 요소 | AI가 할 일 | 모듈 |
| --- | --- | --- | --- |
| 1 | 작품별 게시글 분류 | 글을 **작품·카테고리로 자동 태깅**(경량 LLM 분류). 스팸·저작권 침해 글 필터. 팬 글에서 **새 성지 후보를 발굴** 해 M1 수집으로 환류 | M1 확장·발굴 · 분류·필터 |
| 2 | 여행자 후기 · 경로 공유 | 후기 속 **경로를 파싱해 구조화** → "이 경로 담기"로 내 여정에 이식. 좌표 매칭·검증 후 재사용 가능한 경로로 변환 | M5 경로 파싱 |
| 3 | 커뮤니티 검색 | 작품·장소·팬덤 글을 **시맨틱 검색**. 유사 질문/후기 묶어 보여주기 | M2 검색 |

화면 예시 문구: `팬 포럼` / `동행모집 · 후기` / `작품·장소로 검색` / `눈물의 여왕 — 팬 정보·질문 공유 · 글 2` / `이태원 클라쓰 — 글 1` / `여행자가 만든 경로 — 1. 더현대 → 2. 수제버거집 → 3. 감성카페`

> **커뮤니티는 AI가 소비만 하는 게 아니라 데이터를 공급받는 곳** — 팬들이 올린 새 촬영지·후기가 M1 수집 파이프라인의 신선한 소스가 됩니다.

## 4. 마이페이지 탭

> 패스권 · 판매 경로 통계 · 언어 설정

| # | UI 요소 | AI가 할 일 | 모듈 |
| --- | --- | --- | --- |
| 1 | 패스권 / 구매 상태 | 이 **Entitlement가 AI 차등의 기준**. Backend가 판정한 tier·허용 경로를 AI에 넘겨 **RAG 검색범위·답변깊이·도구 권한** 을 결정. (AI 담당: 티어별 정책·프롬프트·필터 구현) | 권한 → 차등 · 차등 RAG |
| 2 | 내 판매 경로 통계 | 유저가 만든 경로의 조회·구매·완주율 **분석·인사이트**. 인기 경로를 추천 랭킹에 반영 | M4 분석·추천 |
| 3 | 언어 설정 | 선택 언어가 **M6 다국어 파이프라인** 의 스위치 — 추출·요약·RAG 응답·성지명 병기를 해당 언어로. 외국인 관광객 타깃의 핵심 | M6 다국어 |

화면 예시 문구: `Global_Pilgrim` / `K-Content Explorer` / `프리미엄 입장권 — 3-Day Pass` / `AI 가이드 무제한 · 전 경로 열람` / `저장한 장소·루트`

---

> **정리** — 목업의 화면 하나하나가 곧 AI 구현 과제입니다 — 지도 핀·성지 정보(**M1**), 검색·근거(**M2**), 가이드 챗봇(**M3**), 랭킹·개인화(**M4**), 경로 동선(**M5**), 다국어(**M6**), 그리고 이 모두를 관통하는 **패스·구매 기반 차등 정책(권한)**. 이것이 AI 담당자인 내가 만들 범위 전체입니다.
