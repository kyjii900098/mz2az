## 1. 개발 환경 — Docker

- 권호가 작성한 `JiraDocs/MZ2AZ-157 Docker 개발 환경 구성.md` 가이드에 따라 Docker Desktop을 brew로 설치 시도했다.
- 설치가 `docker-credential-osxkeychain` 충돌로 실패했다. 원인은 이 맥에 이미 **OrbStack** (Docker Desktop 대체 프로그램, 7/16 설치)이 있었기 때문이다. 슬랙 코덱스 봇 작업 때 설치했던 것.
- Docker Desktop을 새로 깔지 않고 **OrbStack을 그대로 쓰기로 했다.** `docker` 29.4.0, `docker compose` v5.1.2가 이미 동작하며 가이드의 모든 명령이 그대로 돌아간다.
- OrbStack은 로그인 불필요. 좌하단 "Pro Trial 11 days" 표시는 자동 체험판이며, 만료 후에도 기본 기능(컨테이너·compose)은 무료 등급으로 계속 쓸 수 있다.

## 3. 데이터 V5 → V6 정제

원본: `01_Raw/정승길/data/result/촬영지_TOP_v5_정예4작품.csv` (260행)
결과: **`촬영지_TOP_v6_정예4작품.csv` (164행 × 25컬럼)**

| 단계 | 내용 | 행 수 변화 |
| --- | --- | --- |
| 필터링 | scene_description 없는 행, 네이버 URL 없는 행 제거 | 260 → 187 |
| 장소 미특정 제거 | "화장실"(st_15320) 제거 | 187 → 186 |
| 좌표 쪼개기 병합 | 이화동길33번길 3좌표 → 대표 1행 | 186 → 184 |
| 중복·위성 행 정리 | 한 장면 다좌표(북촌 6곳, 녹사평육교 3곳 등), 설명-장소 불일치 행 12행 제거 | 184 → 172 |
| 장소 사진 없는 행 제거 | place_image_url 결측 8행(용두리 마을 관련 등) 제거 | 172 → 164 |

행 제거 외 반영 사항:

- **place_type 전량 채움** — 결측 64건을 장소명·장면으로 판단해 입력했고, 55가지로 난립하던 기존 표기를 39가지로 정규화했다.
- **별칭 세미콜론 통합** — 도깨비의 두 표기(Guardian…/Goblin)를 전 행 통일하고 검색으로 확인한 별칭을 추가했다. 케데헌은 `KPop Demon Hunters;K-Pop Demon Hunters;케데헌;KPDH;KDH`.
- **scene_description 문장형 재작성** — 명사형으로 끝나던 설명 전량을 목업(목업_작품검색.html)의 합니다체 문장 스타일로 다듬었다.
- **케데헌 수상 내역 입력** — 영화라 드라마 top120 순위(famous_rank) 미해당이므로 award 컬럼에 2026 아카데미 장편애니메이션상·주제가상, 골든글로브, 그래미, 애니 어워드 10관왕을 채웠다. 관객수는 넷플릭스 공개작이라 집계 불가로 비워 둔다.
- **작품 메타 컬럼 3개 추가** — `title_network` / `title_year` / `title_genre` (예: tvN / 2016 / 판타지;멜로). 목업의 "tvN · 2016 · 판타지 멜로" 표기를 프론트에서 조합할 수 있게 분리형으로 넣었다.
- 최종 구성: 눈물의 여왕 70 · 도깨비 58 · 이태원 클라쓰 25 · 케데헌 11행. 남은 결측은 전부 구조적(영화의 famous_rank, 드라마의 award, 전체 audience_acc·recent_rank)이며 MVP1 용도로 확정했다.
