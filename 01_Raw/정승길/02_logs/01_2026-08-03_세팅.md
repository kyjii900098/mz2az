- 권호가 작성한 `JiraDocs/MZ2AZ-157 Docker 개발 환경 구성.md` 가이드에 따라 Docker Desktop을 brew로 설치 시도했다.

## 9. Flutter 검색 탭 구현 (apps/mobile)

V6 164행을 JSON 목데이터로 내장하고 검색 탭을 구현했다. 여러 차례 UX 리뷰를 거친 최종 상태:

- **구조 (목업 §2 준수)**: 네이버 지도 상시 노출 + 바텀시트 3단 드릴다운(목록 → 작품 상세 → 촬영지 상세). 시트는 3단 스냅(14%/42%/최대), 최대 높이는 검색바 바로 아래까지 기기별 자동 계산.
- **네이버 지도 SDK 연동** — `flutter_naver_map` 1.4.4. 클라이언트 ID는 승길이 네이버 클라우드 플랫폼에서 발급, `env.json`(gitignore) + `--dart-define-from-file` 주입. `env.example.json` 견본 제공. Client Secret은 서버용이라 미사용.
- **지도**: 첫 진입 서울 + 인기 성지 12곳 원형 핀. 작품 선택 시 핀 안에 번호가 박힌 마커 + fitBounds. 장소 진입 시 줌 15 확대 — 시트 높이를 읽어 **보이는 지도 영역의 정중앙에 핀이 오도록 pivot 유동 계산**.
- **컨트롤**: "현 지도에서 성지 검색"(상단 중앙 알약, 뷰포트 BBox 필터, N곳·해제 토글), 내 위치(우측 상단, 위치 권한 Info.plist 추가).
- **검색**: 상단 통합 바(검색+카트 한 덩어리). 자동완성은 별칭 칩 표시 + 유력순 랭킹(앞글자>단어시작>포함, 동점 시 인기순), 최상단 결과는 포스터와 함께 크게. **장소 섹션**도 함께 떠서 장소명 검색 가능.
- **촬영지 상세**: 장소 이미지, 카테고리·주소, 담기/네이버 지도(더보기 → Safari로 리뷰·평점), **"이 장소의 장면 · N개 작품이 이곳에서 촬영"** 가로 장면 카드 → 목업 §2.7 스타일 팝업(씬 이미지+작품 배지+설명+담기).
- **장바구니**: 상단 우측 고정(카트 아이콘+뱃지), 담기까지만(로컬 메모리).
- **디자인**: 하늘색(#2F9FE0) 브랜드 + 디자인 토큰(잉크/회색/구분선/radius 16/그림자) 일원화. 하단 탭바는 직접 제작(높이 52px, 칸 구분선).
- 검증: `flutter test` 통과(칩 매핑·장바구니), iOS 시뮬레이터에서 전 동선 실행 확인.
