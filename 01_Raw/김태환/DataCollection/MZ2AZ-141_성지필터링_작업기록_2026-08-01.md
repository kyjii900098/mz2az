## 4. 필터 — 3단계

### 4-1. 매칭과 점수

`place_name` 을 정규화해 본문에서 찾되, **장소명 주변 ±120자에 촬영·성지·장면 단서가 있어야 유효 언급** 으로 센다. 글 제목에 있으면 무조건 유효. "강릉역에서 내려서" 같은 경유 언급을 걸러내기 위함이다.

```
popularity_score = (그 장소의 유효 언급 글 수 ÷ 그 작품 1위의 유효 언급 글 수) × 100
```

작품 내 정규화라 대형작 편향이 없다. 작품 인기도(`famous_rank`)와 장소 인기도를 분리해 앱에서 따로 쓸 수 있다.

### 4-2. 규칙 등급

```
S : 유효언급 3글 이상 + 저자 3명 이상 + 작품 내 1위의 30% 이상
A : 유효언급 2글 이상 + 저자 2명 이상
B : 유효언급 1글 이상 또는 글 제목에 등장
C : 그 외
```

해외 로케이션(116행)과 근접 중복(203행)은 제외. 채택 0곳인 작품만 B등급 상위 3곳까지 구제(27행).

### 4-3. Claude 판정 — 규칙이 못 거르는 것

규칙으로 좁힌 **S/A 1,056곳** 의 근거 문장을 직접 읽고 판정했다. **92곳 제외 · 19곳 장면설명 생성.**

| 제외 유형 | 건수 | 예 |
| --- | ---: | --- |
| 도로명 | 34 | `올림픽대로`, `테헤란로`, `추성1로` — 통과 지점이지 목적지가 아님 |
| 교량·나들목 | 8 | `서강대교`, `잠수교`, `청담나들목` |
| 정류장·역·공항 | 12 | `세검정초등학교 정류장`, `약수역`(딱지남 찾아 헤매는 장면), `인천공항` |
| 근접 중복 (규칙이 놓침) | 8 | `죽도시장(1)`↔`포항 죽도시장`, `카자구루마`↔`우영김밥`, `오라동메밀밭`↔`오라동 메밀꽃밭` |
| 주거·사생활 | 6 | `효자그린빌`, `고려빌라`, `운천주공아파트(재개발)` |
| 방문 불가 | 4 | `대성정밀`(공장), `한온시스템 생활관`(방문 제한 명시) |
| 장소명이 아님 | 4 | `오프닝`, `화장실`, `에이미`(등장인물명), `서울 용산구`(행정구역) |
| 근거 부실 | 16 | 해시태그 나열만 있거나, 근거 글이 "촬영지가 아니다"라고 명시 |

> 마지막 유형이 규칙으로는 불가능한 판정이다. 예) 이태원 클라쓰 `꿀밤포차` 는 유효언급 6글이었지만 근거 글이 **"드라마에 나온 장소는 아니지만"** 이라고 적어 놓았다.

## 7. 신규 성지 후보 182건 — 이 파이프라인의 구멍

필터는 **v4를 모집단으로 고정** 하므로, 블로그에 아무리 자주 나와도 v4에 없으면 존재를 모른다. 코퍼스를 역방향으로 훑어 후보를 뽑았다.

**조건**(셋 다 만족) — 유효 언급 3글 이상 + 저자 3명 이상 + **블로그 글 제목에 1회 이상 등장**. 마지막 조건이 정밀도의 핵심으로, 687건 → **182건 / 85편** 으로 줄였다.

| 유효언급/저자 | 작품 | 후보 |
| --- | --- | --- |
| 37글/40명 | 갯마을 차차차 | 사방기념공원 |
| 28글/32명 | 이태원 클라쓰 | 남산타워 |
| 22글/29명 | 선재 업고 튀어 | **행리단길** |

## 8. 한계

1. **이름 매칭 기반이다.** 블로그가 다른 이름으로 부르는 성지는 §7로 일부 건졌지만 완전하지 않다. 예) `구룡포항 언덕(전망 계단)` 은 블로그에서 "동백이 계단"이라 불려 0글로 떨어졌다.
2. **인기도 ≠ 방문자 수.** "블로그에 많이 쓰였나"일 뿐이다. 진짜 인기도는 권호님의 **유저 이벤트 + 반감기** 로 가야 하고, 이 점수는 **콜드 스타트 초기값** 이다.
3. **최근 편향.** 네이버 검색은 최신 글을 위로 올린다. 구작은 성지가 살아 있어도 글이 적게 잡힌다.
4. **코퍼스는 2026-08-01 스냅샷.** 재수집하면 숫자가 달라진다.
5. **구제 27행은 근거가 약하다.** `decision_note` 가 `작품구제_…` 로 표시돼 있다.
6. **LLM 판정은 S/A 등급만 봤다.** B/C 등급 4,554행은 규칙 판정 그대로다.

## 10. 재현

```bash
pip install requests beautifulsoup4 lxml
python scripts/crawl.py          # 1단계 — 블로그 코퍼스 수집 (161편 / 8,623글)
python scripts/filter_v2.py      # 2단계 — 유효언급 집계·등급·규칙 채택

python scripts/regen.py          # (별도) 최종본 기준 근거·요약 재생성
```

`scripts/decisions/*.jsonl` 이 Claude 판정 기록이다 — 규칙과 다른 건만 담겨 있어(111건) 어디를 손댔는지 그대로 추적된다.

코퍼스(69MB)는 세션 임시 디렉토리에 두고 볼트에 넣지 않았다 — 블로그 본문 전문이라 저작권 문제가 있고, 필요한 건 추출 결과지 원문이 아니다. 근거 URL은 `인기성지_언급근거` 에 남아 있다.
