## MZ2AZ-128 한국문화정보원 영상 촬영지 데이터 확보·검토

**파일** — 검토: [[01_Raw/정승길/data/README|data/README]] §4·§6
**결과물** — 원본 [[혼합_한국문화정보원_원본_2022.csv]] · 변환본 [[혼합_한국문화정보원_스키마.csv]]

| 항목 | 내용 |
| --- | --- |
| 원본 | data.go.kr **15,034행** (2022-11-25 스냅샷, cp949) — 드라마 7,339 · 예능 5,460 · 아티스트 1,962 · 영화 273 |
| 변환 | 팀 15컬럼 규격으로 변환 완료 (id `kcisa_00001`~, utf-8-sig) + 부가 컬럼 phone·opening_hours·break_time·closed_days 보존 → **19컬럼** |
| 라이선스 | **공공누리** — 저장·재배포 자유 |
| 스키마 연결 | `장소설명` 컬럼이 DB `place_i18n.description` 의 수집 소스 ([[MZ2AZ-111 SceneTrip DB 스키마]]) |

> [!warning] 병합 시 743편 유실
> 자체 수집분(kdramamap 476편)과 병합하면 **743편(약 10,500행)이 매칭 실패로 유실** 된다. 다수가 맛집 예능(백반기행·맛있는 녀석들 등). 상세는 data/README §병합 주의.

> [!note] 발굴 경위
> 김상규 멘토링(7/25) — "한국문화정보원의 영상 촬영지 데이터가 성지데이터 수집의 참고자료가 될 수 있을 것".
