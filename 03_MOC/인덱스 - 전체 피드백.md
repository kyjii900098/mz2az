# 인덱스 - 전체 피드백

받은 피드백 전부를 시간순으로.

> [!info] 이 표는 dataview가 실시간 생성한다
> 02_Wiki에서 `type: feedback`인 노트를 자동으로 뽑는다. 이 파일은 손볼 필요 없다.

```dataview
TABLE WITHOUT ID file.link AS "노트", date AS "날짜", act AS "막", mentor AS "멘토", adopted AS "반영"
FROM "02_Wiki"
WHERE type = "feedback"
SORT date ASC
```
