# 인덱스 - 의사결정

우리가 내린 결정과 그 근거.

> [!info] 이 표는 dataview가 실시간 생성한다
> 02_Wiki에서 `type: decision`인 노트를 자동으로 뽑는다. 요지는 각 노트 frontmatter의 `summary`다. 이 파일은 손볼 필요 없다.

```dataview
TABLE WITHOUT ID file.link AS "결정", date AS "날짜", act AS "막", mentor AS "관여 멘토", summary AS "요지"
FROM "02_Wiki"
WHERE type = "decision"
SORT date ASC
```
