## 주제별 지도

> [!info] 이 표는 dataview가 실시간 생성한다
> 각 노트 frontmatter의 `topic` 속성에서 자동으로 묶는다. 한 노트가 여러 주제에 걸리면 여러 줄에 나타난다. 이 파일은 손볼 필요 없다.

```dataview
TABLE WITHOUT ID key AS "주제", rows.file.link AS "노트"
FROM "02_Wiki"
FLATTEN topic AS t
GROUP BY t
SORT key ASC
```
