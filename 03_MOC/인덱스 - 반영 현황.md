# 인덱스 - 반영 현황

**이 인덱스의 목적은 놓친 것을 다시 줍는 것이다.** 그래서 미반영(`pending`·`partial`·`no`)이 위에 온다.

> [!info] 이 표는 dataview가 실시간 생성한다
> 02_Wiki frontmatter의 `adopted`·`adopted_note`에서 자동으로 뽑는다. 노트를 추가·수정하면 바로 반영되므로 이 파일은 손볼 필요 없다. 표가 아니라 코드로 보인다면 읽기 모드(Reading view)로 전환할 것.

## 미반영 — pending · partial · no

```dataview
TABLE WITHOUT ID file.link AS "노트", adopted AS "상태", date AS "날짜", mentor AS "멘토", adopted_note AS "사유"
FROM "02_Wiki"
WHERE adopted != "yes"
SORT adopted DESC, date ASC
```

## 반영됨 — yes

```dataview
TABLE WITHOUT ID file.link AS "노트", date AS "날짜", mentor AS "멘토"
FROM "02_Wiki"
WHERE adopted = "yes"
SORT date ASC
```
