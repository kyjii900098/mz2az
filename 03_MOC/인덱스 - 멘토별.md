# 인덱스 - 멘토별

멘토 한 분이 준 피드백만 모아 보고 싶을 때.

> [!info] 이 표는 dataview가 실시간 생성한다
> 02_Wiki frontmatter의 `mentor` 속성에서 자동으로 뽑는다. 이 파일은 손볼 필요 없다.

## 등장 횟수

```dataview
TABLE WITHOUT ID key AS "멘토", length(rows) AS "노트 수"
FROM "02_Wiki"
FLATTEN mentor AS m
GROUP BY m
SORT length(rows) DESC
```

## 멘토별 전체 목록

```dataview
TABLE WITHOUT ID m AS "멘토", file.link AS "노트", date AS "날짜", adopted AS "반영"
FROM "02_Wiki"
FLATTEN mentor AS m
SORT m ASC, date ASC
```

## 한 분만 보기 — 예: 정문창

아래 블록에서 이름만 바꾸면 어느 멘토든 같은 방식으로 뽑힌다.

```dataview
TABLE WITHOUT ID file.link AS "노트", date AS "날짜", type AS "종류", adopted AS "반영", summary AS "요지"
FROM "02_Wiki"
WHERE contains(mentor, "정문창")
SORT date ASC
```
