> [!summary] 정승길이 8/3 스프린트 회의 결정을 근거로 작성한 초안. 회의 결정이 정본이고 목업은 참고 자료라는 위상을 못 박았다.

### 상세 내용

이 문서는 **"회의 결정이 정본이고, 목업은 참고 자료"** 라는 위상을 문서 맨 위에 명시한다. 목업은 AI로 빠르게 만든 시안이라 팀 의사를 100% 반영한 화면이 아니므로, 색·디자인·UI/UX는 구현하면서 더 낫게 바꿔도 된다는 뜻이다.

**기술 선택은 Flutter 3.44 / Dart, 지도는 네이버 지도 SDK(`flutter_naver_map` 패키지)** 로 확정했다. 프로젝트 경로는 `~/workspace/SceneTrip/apps/mobile`(패키지명 `com.mz2az.scenetrip`)이고, 실행 대상은 iOS 시뮬레이터와 웹(Chrome)을 우선으로 하고 Android는 Android Studio 설치 후 진행한다.

**V6 데이터 컬럼과 화면 요소를 매핑** 했다. 예를 들어 작품 제목·자동완성은 `title`/`title_aliases`, 지도 핀 좌표는 `place_latitude`/`place_longitude`, 장면 설명은 `scene_description`(문장형으로 다듬은 값)에 대응한다. 원본 데이터는 `01_Raw/정승길/1주차_data/result/촬영지_TOP_v6_정예4작품.csv`(164행 × 25컬럼, 4작품)이며, 정승길의 8/3 작업 로그에 따르면 이 V6는 V5(260행)에서 결측 필터링·중복 정리·장소 사진 없는 행 제거를 거쳐 만들어졌다. 구조적 결측(영화의 `famous_rank`, 드라마의 `award`, 전체 `audience_acc`·`recent_rank`)을 제외하면 결측 없는 상태로 확정됐다.

**백엔드에 요청할 API는 6종** 이다 — 작품 자동완성, 작품 검색, 작품별 촬영지 목록, 뷰포트(지도 화면 영역) 기준 촬영지 검색, 촬영지 상세, 인기 촬영지(첫 화면용)다. 장바구니는 MVP1에서 로컬 저장이라 API가 필요 없다.

**목업의 위상은 참고 자료다.** 카테고리 칩처럼 목업이 임의로 만든 값(예: 5종 칩)은 팀 결정이 아니므로, 이 문서는 한국문화정보원 데이터 분류 등 팀 기록을 조사해 임시안(V6 `place_type` 39종을 5칩으로 매핑)을 별도로 제시하고, 최종안은 추후 팀이 확정하도록 남겨 뒀다.

> [!question] 확인 필요 — 네이버 지도 클라이언트 ID 발급 계정, 카테고리 칩 최종안, 지도가 한국 밖으로 벗어났을 때의 처리, 좌표-네이버 SDK 정확도 검증, API 응답 필드 확정까지 5개 항목이 미결로 남아 있다.
