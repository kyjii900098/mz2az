> [!summary] 목업까지 만든 루트 유료 판매를 폐기하고 제휴 수수료 구조로 전환. 2026-07-28 팀 결정.

### 상세 내용

정권호의 `2026-07-27 프로젝트 기획서 수정본 v2` 변경 요약 4-1:

> **BM 전면 교체 — 루트 유료 판매(마켓) 폐기 → 가이드 투어·여행 상품·로컬 제휴 연결에 따른 레퍼럴(제휴 수수료) 구조** (팀 결정 2026-07-28)

**김상규의 지적이 계기로 보인다**(07-25, 김태환 기록):
> **루트/경로 구매는 이용자에게는 의미가 없게 느껴질 가능성이 높다** → 아예 서비스의 유료화로 생각해보라, 경로를 올리는 사람이 (…)
> 하루는 무료 이용, 이후에는 유료 이용으로 진행한다면 **이탈률/지속률도 계산을 할 수 있을 뿐더러 BM의 평가 측면에서도 긍정적인 평가** 를 받을 수 있다.

즉 **"경로 하나를 $2.99에 판다"는 것이 사용자에게 와닿지 않는다** 는 판단이다. 서비스 전체를 기간제로 유료화하는 편이 낫다는 것.

**같은 스프린트에서 함께 정리된 기획 변경들**
1. "실시간 개방 여부, 운영시간 조회" 삭제 → 외부 링크 대체
2. 작품 별칭 검색("별그대"), 장소 타입 카테고리, "현 지도에서 검색"(뷰포트 재탐색) 추가
3. **루트 자동 생성 → 초기 수작업 큐레이션.** AI 자동 생성은 고도화 단계로
4. 초기 데이터를 유명 작품 + 촬영지 인근 유명 식당으로 한정, AI 자동 수집과 수작업 검수 병행
5. **이미지 검색 기능 미포함** 명시

3번이 특히 중요하다. 06-19 기획서의 「AI 기반 여행 일정 자동 생성」이 **초기에는 사람이 만드는 것** 으로 내려왔다. → [[MVP 범위 축소]]

> BM이 세 번 바뀌었다 — ① 단기 구독 → ② 무료·패스·루트 단품 3단계 → ③ 패스 + 레퍼럴. 목업(`목업_SceneTrip_김태환.html`)에는 아직 ②가 그려져 있어 최신 결정과 어긋난다. 목업 갱신 여부 확인 필요.
