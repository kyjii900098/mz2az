> [!summary] 1차 MVP 8/29, 중간발표 9/18~19. 목표일이 8/22에서 8/29로 한 주 밀렸다.

### 상세 내용

**확정 일정**(`프로젝트 결정사항`, 2026-07-28 기준)

| 주차 | 내용 |
| --- | --- |
| 7/27 ~ 7/31 | 데이터 스키마 확정·수집 + 검색·지도 탭 목업 ← 현재 스프린트 |
| 8/3 ~ 8/7 | 검색탭 개발 |
| 8/10 ~ 8/14 | 로그인, 루트(코스) 기능 구현 |
| 8/17 ~ 8/21 | **AWS 교육 주간** (개발 진행 어려움) |
| 8/24 ~ 8/28 | **1차 MVP 구현 마감주** |
| 8/31 ~ 9/17 | 버퍼 + 중간발표 준비 |

- 1차 MVP 목표일 = **8/29**
- 중간발표 = **9/18~19**, 9/14 주는 발표 준비 전용
- 스프린트 리뷰 = 8/1(토) 팀 오프라인
- 공휴일(8/15 등)에는 모이지 않음

**목표일이 밀린 경위**
- 김상규(07-18): "MVP 목표를 정해서 **8월 22일** 정도를 1차 개발 마감 날짜로 정해보자"
- 박재범(07-21): "MVP1 목표는 **8/21~22**"
- 확정(07-27~28): **8/29**

한 주 늦춰진 직접 원인은 **8/17~21 AWS 교육 주간** 이다. 그 주에 개발이 어려우므로 마감주가 8/24~28로 밀렸다.

**박재범의 계획 방법론**
> 계획부터 세우지 말고 각자 파트를 먼저 손대서 개발 속도 감을 잡은 뒤, 앞으로 한 달을 **3일 단위 블록 12개** 로 쪼갠 계획에 합의하라.

정승길의 로드맵에도 같은 말이 있다 — "손대서 속도 감부터 → 그 감으로 **3일 블록 × 4주** 계획을 셋이 합의(금요일)".
