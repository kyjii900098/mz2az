> [!summary] Jira MZ2AZ-111/119/120으로 확정한 수집 스키마. 컬럼명은 영문 통일.

### 상세 내용

| 컬럼 | 의미 | 작성 규칙 / 예시 |
| --- | --- | --- |
| `id` | 행 식별자 (작품×장소 조합 1건) | `st_0001` 형식 연번 |
| `title` | 작품 정식 명칭 | `도깨비` |
| `title_aliases` | 이명·영문명·약칭 | `;` 구분 — `Guardian;쓸찬신` |
| `title_category` | 작품 유형 | `drama` / `kpop` / `movie` / `variety` |
| `title_cast` | 주요 출연진·아티스트 | `;` 구분 — `공유;김고은` |
| `place_name` | 실제 상호명·지명 | `주문진 방파제` |
| `place_type` | 장소 유형 | 카페 / 해변 / 사찰 / 공원 … |
| `place_address` | 도로명 주소 | |
| `place_latitude` | 위도 (WGS84) | 소수점 6자리 |
| `place_longitude` | 경도 (WGS84) | 소수점 6자리 |
| `place_image_url` | 장소 대표 이미지 URL | |
| `place_naver_url` | 네이버 지도·플레이스 링크 | 길찾기 연동용 |
| `scene_description` | **이 장소가 작품에서 어떻게 등장했는지** | 은탁이 우산 들고 김신을 소환하는 장면 |
| `source_url` | 출처 | 위 정보를 확인한 원문 링크 |
| `last_updated` | 최종 수정일 | `YYYY-MM-DD` |

**의도적으로 뺀 컬럼이 있다**(`프로젝트 결정사항`):
- **전화번호 제외** — 외국인이 전화할 일 없음
- **영업시간 제외** — 책임져야 할 범위가 너무 넓어짐

두 번째가 중요하다. 06-19 기획서의 주요 기능에는 "실시간 개방 여부, 운영시간 조회"가 들어 있었는데 이때 **삭제되고 네이버/카카오맵 외부 링크 연결로 대체** 됐다. 이유는 정확성 책임을 지지 않기 위해서다.

**좌표 정밀도 규칙** — "소수점 5~6자리 유지 (5째 자리 ≈ 1m)".

**`source_url` 이 스키마에 들어 있는 것** 이 [[검증된 K-콘텐츠 촬영지 데이터로 재정의]] 의 실물이다. 출처를 컬럼으로 강제하면 검증형 데이터가 된다.

07-28 추가 확정(김태환 기록): **에피소드/화 정보는 `description` 하나의 열로 대체**, `category` 는 `kpop / movie / variety / drama` 4종으로 확정.
