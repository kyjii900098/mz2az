> [!summary] Claude가 기획하고 Codex CLI가 실제 리서치를 수행하되, 결과물은 격리된 폴더에만 쓰고 원본은 건드리지 않는 위임 방식.

### 상세 내용

Claude 세션의 월간 토큰 한도가 소진돼 리서치가 중단될 때, 정승길은 남은 작업을 **Codex CLI**(`codex exec --full-auto`, 웹 검색 활성화)에 넘겼다. Claude가 계획(스크래치패드의 plan-movies.md 등)을 세우고 기존 Claude 에이전트와 동일한 규칙(15컬럼 스키마, source_url 필수, 금지 출처 배제, 지어내기 금지)을 그대로 넘긴 뒤, Codex가 실제 웹 리서치와 CSV 작성을 수행하는 구조다.

**격리 원칙** 을 지켰다 — Codex가 만들고 고친 파일은 전부 `01_Raw/정승길/data/codex/` 아래에만 두고, Claude가 동시에 작업 중이던 드라마(눈물의여왕·내남편과결혼해줘 등)는 조사·병합 대상에서 제외했다. `README_codex.md`·`result_codex.md`는 **Codex 작업을 시작한 시점의 원본 스냅샷** 으로 보존하고, 이후 Claude가 상위 원본 파일을 갱신해 내용이 달라져도 이 스냅샷은 덮어쓰지 않았다. 상위 폴더의 원본 CSV·README·result 파일에는 Codex가 직접 쓰지 않는다 — 병합은 Claude가 검수 후 별도로 수행한다.

**7/30 오후 위임(영화 15편 + 드라마 장면설명 2작품)** 에서는 영화 15편의 촬영지를 새로 수집(53곳, 과속스캔들은 근거 부족으로 0곳 유지)하고, 드라마 미지의서울 81곳·엄마친구아들 104곳의 잔여 장면설명을 채웠다(각각 63/81, 61/104). Claude가 산출물을 검수해 15컬럼 규격 위반·출처 없음·금지 출처가 0건임을 확인한 뒤 본체에 병합했다.

**촬영지 0건 영화 리서치** 에서는 더 큰 성과가 나왔다. 관객수·수상 정보로 촬영지 0건 영화 477편의 우선순위를 매기고 1~36위까지 조사한 결과, **30편에서 검증된 신규 촬영지 49곳** 을 추가했다(신과함께-죄와 벌 3곳, 헤어질 결심 3곳 등). 나머지 6편은 근거가 부족해 `researched_no_verified`로 보류했고, 441편은 아직 미조사 상태다. 기존 영화 6편의 장면설명 62곳도 함께 검증해 32곳이 통과 기준을 만족해 병합됐다. Codex는 자체 검증 장부도 남겼다 — 주장 111건 중 81건 통과·30건 미확정·반증 0건으로, 최종 평가는 PASS다.
