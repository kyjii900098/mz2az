> [!summary] 옵시디언 볼트를 깃으로 관리하는 팀 공용 위키 — 지금 이 볼트가 그 결과물이다.

### 상세 내용

김상규가 07-11과 07-18 두 차례에 걸쳐 세팅을 지시했다.

**위키 (07-18)**
> 팀 위키… 이걸 결국 하나로, 공통된 지식으로. 컨플루언스가 좀 불편하니까 **옵시디언으로, 깃으로.** 어차피 md 파일이니까 — 태환.
> 이미지 같은 대용량은 구글 드라이브에 해놓고 MCP 설정. 코드 파일 같은 것도 링크로. **공통의 기획을 PR로.**

김태환의 기록(`2026-07-18`)이 더 구체적이다:
> WIKI의 주제별 폴더 안에 index를 둔다. **위키 최상위에 claude.md가 있고, 이걸 기반으로 클로드가 탐색을 진행한다.** PR이 오면 확인하면 된다. 팀 공용 볼트는 따로 만들어서 하면 좋을 것 같다.

같은 자리에서 김상규가 남긴 한 줄이 이 볼트의 파이프라인을 예고한다:
> **01_RAW에 ppt 넣으면 1차로 pdf로 바꾸고 md로 전사하는 걸 넣자.**

**Jira / 애자일 (07-11)**
> epic: 큰 단위(프론트엔드 개발) / story: 1주일 / task: 하루하루.
> PO가 백로그를 쓴다(우선순위도). 스프린트 플래닝 미팅(매주 월) → 스프린트 백로그 → 스토리 → 태스크. 끝나면 스프린트 리뷰, 스프린트 회고. 데일리 스탠드업 15분.
> **스크럼 마스터를 AI로 만듦.** 어제 claude와 대화한 로그를 옵시디언에 남겨두고, 다음 날 스크럼 마스터가 보고 뭐가 됐는지 판단. PO도 AI로 스킬을 만들어서.

**깃허브 전략** 도 이때 확정됐다 — GitHub Flow(main은 항상 배포 가능, 브랜치 파서 작업, PR로만 머지), 브랜치명·커밋 메시지에 Jira 티켓 키 포함(`MZ2AZ-91-브랜드-네이밍`, `feat: 지도 SDK 적용 (MZ2AZ-10)`).
