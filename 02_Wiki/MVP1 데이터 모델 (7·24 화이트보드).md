> [!summary] 7/24 오프라인 회의에서 화이트보드에 그린 5개 엔티티 — 장면·장소·코스·커뮤니티·유저.

### 상세 내용

박재범 멘토링(7/21) 후 "금요일에 세세한 부분을 확정짓는다"고 한 그 금요일의 산출물이다.

**엔티티와 필드**

| 엔티티 | 내용 |
| --- | --- |
| **장면** | `[영상 이미지]` → (메타 정보) → 장면 설명 |
| **장소** | `[실제 장소 이미지]`(구글 API 이미지 - 대표) → (메타 정보) → 리뷰(이미지, user) / POI 정보 |
| **코스** | `[…정보]` → ① 순번 ② 설명(여행계획) |
| **커뮤니티** | `[게시판]` |
| **유저** | (빈 박스 — 이 시점에 미정) |

**관계**: 장소 : 장면 = **1 : N** (장소 하나에 장면이 여럿)

**두 번째 사진에 추가된 것**
- **포스터 API** — 작품 포스터를 API로 가져온다
- **축약 : LLM** — 장면 설명에서 코스 설명으로 가는 곡선 화살표에 붙은 라벨. 즉 **장면 설명을 LLM으로 축약해 코스 설명을 만든다**
- 좌하단 파란 메모: `MVP1 범위` / `팝업` ← `현지 활성화` / `코스만 늘리면` / `동적 / 정적`

**같은 날 팀이 결정한 것**(김태환 `2026-07-24`):
1. MVP 1은 우리가 추가한 경로만 넣기 (아웃소싱 정보 없음)
2. 장소 핀에 **장바구니 기능** 추가
3. 경로여정 탭에서 코스 클릭 시 코스 정보 표시
4. **작품검색 탭은 동적 지도, 경로여정 탭은 정적 지도** (화이트보드의 `동적/정적` 메모와 대응)
5. 맵 API는 평점·리뷰를 제공하지 않는다 → **MVP1에서는 식당 정보를 추가하지 않는다**
6. 카카오맵은 장소별 고유 key를 제공하나 다운로드 수가 적고 SDK를 지원하지 않는다

5번 문제가 나흘 뒤 [[Google Places 저장 금지와 표시 허용]] 으로 풀린다.
