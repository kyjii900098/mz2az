> [!summary] 기능이 계속 깎여 나간 궤적. 7개 기능 → 4개 → MVP1은 3개.

### 상세 내용

**축소의 궤적**

| 시점 | 범위 |
| --- | --- |
| 06-19 기획서 | 검색·지도·챗봇·일정·블로그·커뮤니티·광고까지 (스스로 "자칫 범위가 너무 커질 위험"이라 적음) |
| 06-19 예상문제 대응 | MVP = 촬영지 검색 · 지도 정보 제공 · AI 여행 코스 추천 · 루트 공유/방문 인증 **4개**. 광고·결제·고도화 개인화는 후속. **서울·부산·경주로 지역 제한** |
| 07-13 피봇팅 | MVP = 촬영지 검색 · 지도 상세정보 · 루트 생성/편집 · 커뮤니티 |
| 07-24 로드맵 | **MVP1 = 앱 메인 + 장면 탐색 + 마이코스 3개.** 커뮤니티·루트마켓·개인화·경로 최적화는 MVP2~3 |
| 07-28 수정본 v2 | 루트 **자동** 생성 → 초기 **수작업** 큐레이션. 이미지 검색 미포함 |

**버리는 순서까지 정해뒀다**(Q&A 방어집):
> 버리는 순서를 정해뒀습니다 — **커뮤니티 고급 기능 → 웹 고도화 → 다국어 범위 축소.** 검색·지도·기본 추천(핵심 가치)은 절대 사수합니다.

**일정 리스크가 큰 구간도 스스로 지목했다**:
> 데이터 구축(6~7월)과 **영상-장소 매핑 정확도** 입니다. 그래서 이 구간에 검증 파이프라인을 함께 투입하고, **어려운 비전 매핑은 후속으로 미뤄** 일정 리스크를 사전에 잘라냈습니다.

이 판단은 [[장면 설명이라는 병목]] 실측치로 뒷받침된다 — 영상에서 장면을 뽑는 일이 실제로 6%밖에 안 됐다.

**"범위를 좁힌 것 자체가 버퍼"** 라는 논리도 있다:
> 일정에 버퍼가 안 보입니다. 지연되면요? → **범위 자체를 MVP로 좁힌 게 버퍼입니다.**
