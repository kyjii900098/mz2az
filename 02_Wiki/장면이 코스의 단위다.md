> [!summary] "같은 장소라도 어느 장면 보고 온 건지" — 장소가 아니라 장면이 코스의 최소 단위라는 결론.

### 상세 내용

7/24 화이트보드의 코스 컬럼에 빨간 펜으로 덧붙은 주석이 이 노트의 전부다.

```
② 설명 ( 여행계획 )
   ↳ 작품과 관련된 설명
     ( 같은 장소라도 어느 장면 보고 온 건지 )
```

**왜 이게 결정적인가.**

일반 여행앱은 **장소** 가 단위다. 경복궁은 하나의 POI고, 누가 왜 가든 같은 설명이 붙는다. 그래서 [[사무국 평가의견]] 이 "일반 여행 서비스와 큰 차이가 없다"고 했고, [[기획 발표 후 심사위원 지적 8건]] 4번이 "다른 여행앱 기능의 한 부분 아닌가"라고 물은 것이다.

**장면을 단위로 잡으면 달라진다.** 같은 경복궁이라도
- 「케이팝 데몬 헌터스」 2화 악령 소환 장면을 보고 온 사람
- 「눈물의 여왕」 어느 장면을 보고 온 사람

에게 **다른 설명, 다른 앞뒤 동선, 다른 코스** 가 붙는다. 장소는 겹쳐도 코스는 겹치지 않는다.

이것이 박재범이 말한 **"코스 = 여행지의 시퀀스한 트라젝토리 한 에피소드"**([[콘텐츠 모델링 — 장면 플레이스 코스]])의 실무적 함의다. 그리고 데이터 모델에서 **장소 : 장면 = 1 : N** 인 이유이기도 하다 — 장소를 재사용하되 장면마다 다른 맥락을 매단다.

목업이 이 원리를 그대로 보여준다. 「홍대 걷고싶은거리」 카드에 `1화` 배지가 붙고 "오프닝 공연 장면 — 멤버들이 처음 악령을 만나는 버스킹 무대"라는 설명이 달린다. 다음 추천은 `2화` 경복궁 앞 거리, `8화` N서울타워 — **회차 순서가 곧 동선** 이다.
