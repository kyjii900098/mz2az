> [!summary] 7/27~7/31. 목표를 딱 둘로 못 박았다 — 데이터 스키마 확정·수집, 검색·지도 탭 목업. 개발 착수는 하지 않는다.

### 상세 내용

| 항목 | 내용 |
| --- | --- |
| 기간 | 2026-07-27(월) ~ 07-31(금) |
| 스프린트 리뷰 | 08-01(토) — 팀 오프라인 |
| 목표 | **딱 2가지** — ① 데이터 스키마 확정 + 수집 ② 검색·지도 탭 목업 확정 |
| 개발 착수 | **이번 주는 아님.** "다음 스프린트엔 무조건 개발에 들어갈 수 있도록" |

> 애자일 원칙 재확인: 이번엔 **검색·지도 탭에만** 집중한다. **"너무 다 하려고 한다"** 는 지적이 회의 내내 반복됨.

**수집 대상** — K-콘텐츠 전반(유명 드라마 / 영화 / OTT / K-POP 관련 장소 / 예능). "일단 K-콘텐츠를 다 넣고 나중에 필터링" 방향.

**수집 방식** — 확정된 컬럼(스키마)을 **AI에게 던져서 수집** → 빈 칸은 각자 눈으로 확인.

**실제 산출물**(정권호, 07-28): 6,179행 / 185개 타이틀. 네 차례에 걸쳐 수집.

| 차수 | 범위 | 행 |
| --- | --- | ---: |
| 1차 | 지정된 14개 작품 | 183 |
| 2차 | 글로벌 스테디셀러 드라마 10 + 2026 신작 2 + K-POP 글로벌 톱 10팀 | 132 |
| 3차 | 폭싹 속았수다 + 한국 대표 영화 12편 + 태양의 후예 + 런닝맨 | 48 |
| 4차 | **KDramaMap 1~6페이지 144개 드라마 일괄 수집** | 5,816 |

출처 URL 접속 검증 **241/241 통과**.

**두 사람의 파일을 일부러 안 합쳤다** — 정권호 6,179행과 정승길 49행은 작품명 표기(한국어 vs 영어)와 K-POP 모델링 방식이 달라 의도적으로 병합하지 않았다. 장소 기준 13곳이 겹친다.

**07-28 회의에서 추가 확정**: MVP1은 외국어로 **영어만** 제공, 에피소드/화 정보는 `description` 한 열로 대체, category 4종 확정, Jira 스프린트 결과는 옵시디언 `JiraDocs` 로 저장.
