## 2. 데이터 및 데이터 컬럼

대상: 유명 드라마/OTT, K pop 관련 장소, 예능
포맷은 **CSV**, 컬럼명은 **영문으로 통일** 한다. 한 행 = **작품 × 장소 1건**.
템플릿 `assets/촬영지_수집_템플릿.csv` / 컬럼 정의 `JiraDocs/MZ2AZ-111 촬영지 데이터 수집용 스키마.md` (MZ2AZ-119 / MZ2AZ-120)

| 컬럼 | 한글 | 작성 규칙 |
|---|---|---|
| `id` | 행 식별자 | `st_0001` 형식 연번 |
| `title` | 작품 정식 명칭 | `도깨비` |
| `title_aliases` | 이명·영문명·약칭 | `;` 구분 — `Guardian;쓸찬신` |
| `title_category` | 작품 유형 | `drama` / `movie` / `variety` / `kpop` |
| `title_cast` | 주요 출연진·아티스트 | `;` 구분 — `공유;김고은` |
| `place_name` | 실제 상호명·지명 | `주문진 방파제` |
| `place_type` | 장소 유형 | `카페` / `해변` / `사찰` / `공원` … |
| `place_address` | 도로명 주소 | `강원 강릉시 주문진읍 …` |
| `place_latitude` | 위도 (WGS84) | **소수점 6자리** — `37.895123` |
| `place_longitude` | 경도 (WGS84) | **소수점 6자리** — `128.831456` |
| `place_image_url` | 장소 대표 이미지 URL | 직접 링크 |
| `place_naver_url` | 네이버 지도·플레이스 링크 | 길찾기 연동용 |
| `scene_description` | 작품에서 어떻게 등장했는지 | **몇 화 몇 신** 포함 |
| `source_url` | 출처 | 정보를 확인한 원문 링크 |
| `last_updated` | 최종 수정일 | `YYYY-MM-DD` |

- **전화번호 제외** — 외국인이 전화할 일 없음
- **영업시간 제외** — 책임져야 할 범위가 너무 넓어짐
